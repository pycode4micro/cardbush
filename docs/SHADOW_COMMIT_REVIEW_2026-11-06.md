## 确认的问题

| 问题 | 触发与影响 | 修复 |
| --- | --- | --- |
| 来源轮次静默回退 | 指定的运行轮次尚未登记或已不可用时，Shadow 自动引用上一轮；空会话也能创建空上下文 | 明确验证目标轮次，暂不可用时提示重试，不创建错误的临时会话 |
| 压缩上下文被展开 | Shadow 直接拼接原始消息，忽略历史摘要及当前轮的压缩检查点 | 由 Runtime 同步读取历史与安全的当前轮边界，复用已有上下文投影，并冻结模型上下文 |
| 活跃消息展示不完整 | 活跃轮单条映射跳过附件恢复、追加分段及维护内容过滤 | 活跃轮复用历史投影；保留附件和追加边界，隐藏压缩过程文本，不伪造最终回复状态 |
| 会话列表携带大块冻结历史 | 冻结当前轮存于 metadata，摘要和派生索引再次复制该数据 | 摘要排除 `sourceActiveTurn` 和 `sourceModelMessages`；恢复 Shadow 时按需读取完整临时会话 |
| 切换 Shadow 后状态串扰 | 原临时会话未关闭、历史未清空，旧请求的 finally 可以清除新请求的运行状态 | 关闭被替换的会话，清空旧显示，按会话及请求身份处理迟到回调 |

前三项增加回归后，在修复前确实失败；修复后通过。窗口切换覆盖了旧请求延迟结束时，新请求仍应保持运行中的场景。

## 边界与兼容

- 父会话在推理或执行工具时仍可打开 Shadow。读取不会停止父执行、重放工具或复制尚未闭合的工具调用。
- `runtime.get_session` 的 `includeActiveTurn: true` 完整读取可同时返回 `activeTurn` 与 `modelContext`；可选的 `throughTurnId` 选择精确边界。普通历史读取不增加上下文副本。
- `modelContext` 由既有上下文组装器生成，包含有效压缩和覆盖关系，不继承父 Agent 的系统前缀。Shadow 自身的权限约束继续由 Runtime 执行。
- Shadow 创建时保存模型投影，后续父会话完成、继续压缩或前端模块重载均不改变已冻结的上下文。兼容已有未保存模型投影的旧 Shadow 记录。
- 会话索引升级至版本 2，旧索引从原始日志重建。原始日志和完整读取仍保留冻结数据；列表和窗口公开记录不重复携带这些大字段。
- 与统一的 `environment.agents` 登记保持兼容，没有另建执行状态来源。
