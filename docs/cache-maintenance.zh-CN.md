# 本地存储维护

[English](cache-maintenance.md) · [简体中文](cache-maintenance.zh-CN.md)

设置提供三项操作，均不删除项目文件、任务工作区、插件／Skill、凭据、草稿、累计用量或服务商缓存。不整体清空浏览器 localStorage/IndexedDB；删除历史只裁剪所属会话的展示缓存。

| 操作 | 归属与保留规则 |
| --- | --- |
| 清空会话记录 | Runtime 先预检所有任务再删除；活动任务和独立工作区会阻止操作。关联自动化暂停，但定义及结果保留。 |
| 清空日志 | 使用应用日志写入器的相同路径及旧 product-host 日志目录。24 小时后的崩溃转储／元数据可移除，Crashpad 数据库／设置保留。新诊断日志在 8 MiB 轮转，保留三个旧文件。 |
| 清空应用缓存 | 回收无引用 Runtime 数据、过期临时目录和 Electron HTTP／代码／着色器缓存；使用 Electron API，包含持久分区，不清除凭据或应用存储。 |

## Runtime 保留规则

删除单个会话先确认持久删除，再扫描无关缓存。连续删除共用空闲一秒后的延后回收。回收等活动工作结束；会话列表／读取仍可用，新执行或修改在继续前取消后台扫描。被取消扫描在空闲时按新引用重试。显式清缓存／清空历史仍返回清理结果。退出取消延后工作；无法读取的存储留待后续删除或显式重试。

`cacheMaintenance.ts` 收集存储所有者声明的条目，标记保留会话、恢复检查点、自动化计划／结果和打开的 MCP Apps，再沿执行日志跟踪引用，不写第二份执行事实库。文件 memo 编号不复用：小型分配／定位索引保留，无引用执行载荷可删除。

所有者涵盖事件、工具执行、协调状态、子代理记录、MCP App 范围／上下文／观察、插件 Hook／后台交付状态、图片、redo 和过期部分文件。子会话通常随父会话清理，其他保留来源引用或独立工作区会保护它们。图片／redo 哈希与跨会话 memo 引用保持底层记录可达。

维护避开前台 Turn、排队／已准入执行、App 操作及后台活动，不执行任务或推断其结果。所有权／读取错误在删除前中止引用收集；删除错误报告部分清理，可重试。文件系统链接不遍历。日志归属读取有界，保留日志正文以 64 KiB 分块流读，孤立正文不读取。

内置截图使用 Runtime 配置的 `captures` 目录；Product Host 另提供旧内置临时截图目录用于兼容。两者都保留有引用或不足 24 小时的截图。用户自定义截图输出目录不会交给维护器。

## 临时目录

市场预览 30 分钟过期，包括旧进程遗留。插件导入／安装／获取和模型预览崩溃残留 24 小时过期。启动及显式维护时清理。活动暂存带进程归属；当前预览、其他活动所有者、链接目录和 `previous` 回滚备份受到保护。归属文件在可安装插件载荷之外。

## 扩展规则与验证

新增可丢弃存储必须声明所有者、引用键、有界引用读取器和移除方法，注册到 Runtime／宿主维护，并补充真实文件系统保留测试。用户产物和持久业务数据不能放进这些回收器。

运行 `npm run test:cache-maintenance`。夹具覆盖重启孤立数据、共享图片／redo、跨会话 memo、子会话、自动化上下文、恢复、忙碌预检、符号链接、临时租约／回滚备份、部分错误、96 MiB 孤立日志及保留 cookie/localStorage/IndexedDB 的隔离 Chromium。设置测试覆盖入口、忙碌、错误反馈与主题。所有删除路径都为新建夹具，不清理正在运行的产品配置。
