# Runtime 稳定性优化与验证

本次针对 `local-9af20bb9-93cb-49ef-9cf9-5a26487e6ad9` 的并行执行记录发现的架构问题，调整流式事件粒度、工具标题兼容和共享资源协调。没有修改该任务所操作的 HeartLink 项目，也没有重新执行模型请求。

## 流式事件与回放

- 每个文本片段的首个增量立即发布，后续增量按 40 ms 或 2,048 字符合并。在分配事件 ID、序号和写日志之前合并，已经发布的事件不可变。
- 切换思考/正文、进入工具调用、收到用量/结束事件，以及取消、异常收尾时刷新待发内容。计时器失败回到模型轮次错误处理，不形成未捕获的计时器异常。
- 模型消息、工具回执和 Provider replay 不参与合并；父子用量、输出预算和 cache chain 不变。
- 序号回放直接定位数组偏移；同时带序号和事件 ID 的游标优先直接校验，保留旧格式日志兼容与非法游标检查。
- 旧日志不改写；这次优化减少新执行的日志、内存事件对象和推送次数，不是删除历史记录。硬崩溃时最多可能损失尚未发布的一个合并窗口，恢复仍以已持久化事件和检查点为准。

## 工具标题

Runtime 与界面共用 `normalizeToolDisplay`，兼容语言对象、被 JSON 编码的语言对象和旧单语言文本。先解析再清理/截短，避免把语言映射显示为 JSON。历史记录在读取展示时处理，不改写原消息或缓存前缀。损坏或截断的 JSON 使用本地化工具名称兜底，不猜测缺失内容。

## 共享资源声明

`terminal_exec.exclusive_resources` 接受最多 16 个路径或 `host:name` 标签。例如编译时声明项目根目录，运行采集测试时声明可执行文件与 `host:gpu`。相对路径基于 `cwd`，目录与后代路径互斥，Windows 路径忽略大小写。

- 所有资源一次性检查并占用；冲突返回 `terminal_resource_busy` 与持有者标识，不启动命令，不留下部分占用。
- 占用持续到进程树结束，包括工具返回后台句柄以后。停止或自然退出后释放；启动失败同样先完成清理再发布失败回执。
- 文件写入/编辑使用同一个协调器，因此声明项目根目录的构建会与目录内编辑互斥。
- 无冲突的任务保持并行。当前采用明确冲突回执，由代理协调已有任务完成后重试，没有增加隐式命令重放或无限等待队列。

边界：这是同一个 Runtime 进程内的协作机制，需要相关终端使用一致的声明；不是 OS 文件锁，不约束外部进程、未声明的终端或其他 Runtime 实例。直接 SSH 尚无等价协调实现，携带声明时在授权和发送命令之前明确拒绝；远端 CardBush Agent 使用其自己的 Runtime 协调器。

## 验证覆盖

相关 174 项测试通过，Protocol/Runtime 构建、界面与 Electron TypeScript 检查通过。

- 合并首字延迟、定时刷新、批量边界、工具/通道切换、取消后的尾部刷新、持久化重启、游标续读、写盘失败传播。
- 父子用量与预算隔离、cache chain、压缩与恢复、工具副作用不重复、子会话只向父会话提供输入与最终输出。
- 工具标题实时与历史渲染、中英文切换、损坏 JSON 兜底。
- 真实终端的后台占用、跨管理器冲突、取消观察不释放运行中进程的占用、自然退出、停止、启动失败后立即复用资源。
- 原有工作区读写、终端完成通知和 SSH 路由回归。

运行时改动在重新启动 CardBush 后用于后续执行。本次不主动重启用户正在使用的应用。
