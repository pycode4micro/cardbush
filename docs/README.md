Current usage and maintenance guides are paired below. These pages follow the source tree; a source feature is not necessarily in the npm or Store release you installed. See the [release record](releases/1.0.13.md) and [installation guide](INSTALLATION.md). The remote worker migration is a current-source preview requiring matching builds at both ends.

Historical investigations, benchmark results and licensing records retain their original language and dates. They describe the measured version, not a current support guarantee. Executable skills and generated schemas are not translated copies of product documentation.
