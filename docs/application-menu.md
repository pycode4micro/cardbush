# 应用菜单

标题栏提供会话返回、前进，以及文件、编辑、视图、帮助菜单。菜单复用现有会话、项目、预览和设置操作；未提供新窗口、临时会话、账户注销等尚未实现的能力。顶部缓存按钮已移除，清理仍在 **设置 → 数据与维护** 中。

- 文件：新会话、打开项目文件夹、打开文件、关闭窗口和退出应用。关闭窗口沿用托盘行为，退出走现有应用退出流程。
- 编辑：对打开菜单前的编辑器执行撤销、重做、剪切、复制、粘贴、删除、全选。保留输入框及富文本选区，浏览器编辑操作仅能指向本窗口所属的 WebContents。
- 视图：侧边栏、右侧栏、审查、会话历史、Shadow、浏览器、搜索、会话导航、界面缩放和全屏。当前上下文不支持的操作禁用。
- 帮助：项目文档、可自定义快捷键、诊断与关于、反馈及发布版本。链接来自应用自身的仓库地址；“查看发布版本”打开发布页，不代表具备自动更新器。
- 支持 Team 的运行时保留 Beta 入口。

常用默认快捷键：`Ctrl+N` 新会话，`Ctrl+O` 打开文件夹，`Ctrl+P` 打开文件，`Ctrl+F` 搜索，`Ctrl+B` 切换侧栏，`Ctrl+Alt+B` 切换右侧栏，`Ctrl+,` 设置，`Ctrl+/` 快捷键设置，`F11` 全屏。菜单提示跟随设置中的绑定。

会话返回/前进使用 `Ctrl+[` / `Ctrl+]`，记录当前窗口访问过的会话；返回后打开另一会话会替换前进分支。`Ctrl+Tab` 继续在最近访问的两个会话之间切换。已删除会话会从导航记录移除，后台运行不会改变访问顺序。

`Ctrl+R` 只刷新当前预览。主进程仍拦截应用页面刷新，再将按键传给菜单操作；没有活动预览时不刷新任何页面。图片弹窗保留自身缩放和键盘操作。

菜单支持鼠标切换、方向键、Home/End 和 Esc，小窗口中可滚动。`npm run test:window-menu` 在隔离 Electron 窗口验证真实编辑操作、选区恢复、导航与删除、快捷键重设、弹窗隔离、菜单布局及 IPC 归属检查，不访问用户会话数据或剪贴板。
