# 文件引用与交付校验

[English](FILE_REFERENCES.en.md) · [简体中文](FILE_REFERENCES.md)

新消息使用普通 Markdown 文件链接。HTML 文件可以从链接打开预览。远程任务将产物放进当前工作区，并在最终回复里链接文件的绝对路径。工作区外的插件产物经授权复制后，复用同一传输和校验流程。依据脚注中的文件链接不会触发自动传输。

历史 `cardbush-memo:` 链接从 `.file-memo-references` 索引和原始工具执行记录中解析，保留原有的备注、目标和访问边界。已保存的工作区外文件回执仍可用于历史交付。

兼容原有包含会话、回合和工具调用 ID 的长链接。历史链接若抄错工具调用 ID，仅在当前消息的会话、回合、文件名都匹配，且编辑距离不超过 2 的候选只有一个时恢复。数字链接不进行近似匹配，歧义也不猜测目标。

最终回复中的旧 Memo 链接仍校验目标和可访问性，忽略代码示例。遇到无效链接，保留原消息和已有操作，在原上下文后追加一次内部纠正请求，提供可访问文件的链接。第二次仍失败时报告“文件链接需要修正”，不重复执行之前的工具，不循环重试或改写缓存前缀。

界面在链接原位置显示本地化说明和“重试”；正常刷新或重试不会打开系统错误弹窗。引用校验失败、文件不可访问、文件已经变化和临时通信失败分别处理。历史错误引用的恢复使用消息自身的来源信息，不依赖当前选中的会话。

验证入口：`packages/bush-runtime/test/fileMemo.test.mjs`、`scripts/test-file-memo-ui.cjs`、`scripts/test-markdown-format.mjs`。
