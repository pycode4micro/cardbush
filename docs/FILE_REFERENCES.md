# 文件引用与交付校验

`remember_file` 返回简单的文件 ID（`file_1`、`file_2`）、链接（`cardbush-memo:1`）和可直接复制的 `markdown`。文件 ID 用于本会话查询；链接序号由宿主统一分配，因此父子会话、Shadow 和历史预览中的同一链接始终指向同一记录。

链接映射保存在工具执行目录的 `.file-memo-references` 中，只记录序号与原始执行位置，不重复存储文件内容或备注。写入后 fsync，使用校验和检查，重启后恢复原编号；已建立过索引的标记用于阻止索引意外丢失后从 1 重新编号。取消操作可留下未使用的编号，不能回收后分配给其他文件。实际备注仍取自不可变的工具执行记录；同一文件的后续修订生成新引用，原引用保留原备注。

兼容原有包含会话、回合和工具调用 ID 的长链接。历史链接若抄错工具调用 ID，仅在当前消息的会话、回合、文件名都匹配，且编辑距离不超过 2 的候选只有一个时恢复。新数字链接不进行近似匹配，歧义也不猜测目标。

最终交付前检查 Markdown 文件引用及文件是否可访问，忽略代码示例。遇到无效链接，保留原消息和已有操作，在原上下文后追加一次内部纠正请求，提供可访问文件的链接。第二次仍失败时报告“文件链接需要修正”，不重复执行之前的工具，不循环重试或改写缓存前缀。

界面在链接原位置显示本地化说明和“重试”；正常刷新或重试不会打开系统错误弹窗。引用校验失败、文件不可访问、文件已经变化和临时通信失败分别处理。历史错误引用的恢复使用消息自身的来源信息，不依赖当前选中的会话。

验证入口：`packages/bush-runtime/test/fileMemo.test.mjs`、`scripts/test-file-memo-ui.cjs`、`scripts/test-markdown-format.mjs`。
