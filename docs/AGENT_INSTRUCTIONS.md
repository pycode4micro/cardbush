# AGENTS.md 与设置入口

设置 → 全局约束编辑应用用户目录中的 `AGENTS.md`。这是全局规则唯一的持久化来源；设置不再维护按项目区分的提示词，也不再从旧项目上下文 localStorage 读取内容。

每次开始新的根任务轮次时，客户端读取文件正文，并以 `user` 角色加入请求前缀：

1. 全局文件适用于所有会话，包括纯会话和子任务。
2. 项目模式从文件系统根目录依次读取到实际工作目录的 `AGENTS.md`，注明每份文件的路径与作用目录。
3. 更具体目录的规则仅适用于其子树。尚未进入的深层子目录不会被递归扫描、全文注入到整个项目；模型在处理相应子目录时按需读取。

正文包含在 `<INSTRUCTIONS>` 中，不以路径提醒替代，也不使用 `developer` 角色注入。全局消息位于项目、工作目录等可变信息之前；文件内容未改变时，不同会话的全局前缀保持一致。实际缓存命中仍取决于供应商、模型、工具集合等请求条件。

运行中的轮次使用开始时的规则快照，后续新轮次重新读取文件。子任务继承本轮规则及其作用范围。设置保存使用文件版本校验和原子替换；读取、保存失败会报告错误，外部修改后不能用过期编辑静默覆盖文件。

界面入口：

- 添加：文件和文件夹、任务计划。
- Skills：设置 → 插件 → Skills，或输入框 `/skill`。
- Git 分支：项目的工作区详情，支持任务开始前选择分支；运行中禁用切换。
- 视觉功能：设置 → 模型管理 → 模型输入，保留原来的全局开关范围。

回归命令：`npm run test:global-instructions`。
