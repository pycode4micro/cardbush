# 2026-09-29 本地交付验证

本文为 1.0.4.0 打包时的历史记录；随后新增的 Browser Use/Edge 和界面修正见 [本次提交准备](MSIX_STORE_RELEASE.md)。本文测试数、包摘要和安装证据不自动覆盖后续代码。

环境：Windows 11 x64，Node.js 24.20.0，Electron 42.8.1。此记录覆盖会话与子代理、Source、统一设置和浏览器连接器的累计修改，不代表 Store 认证完成。

## 收尾修复

- 子代理继续复用主会话的消息、工具、输入框和停止操作；运行状态与历史装载分开处理，避免刷新导致闪烁或漏掉历史。
- Electron stream 请求不再发送空白 `cursor.lastEventId`，保留合法事件 ID 和 `afterSequence: 0`，协议校验没有放宽。
- 窄会话栏为工具按钮保留空间，缩短风格标签；极窄栏使用紧凑控件，避免队列按钮被裁切和发送按钮溢出。
- 回归夹具同步 Source 默认状态、连接器专属目录、Chrome 116/WebSocket 声明和新增 `/style` 命令。远程 Agent 测试等待会话加载后的权限控件，避免读取已卸载的欢迎输入框。

## 验证方式

以 `scripts/run-release-tests.mjs` 为发布回归清单，失败定位后从对应阶段继续；修改测试夹具时重跑受影响用例，未反复执行已经通过且实现未变的运行时大套件。

- 工作区包测试共 1,176 项；Chrome 声明旧断言修正后，对应测试通过。其余 1,170 项通过，5 项因 Windows 不适用的 POSIX/Linux 条件跳过。
- 生产构建、前端和 Electron TypeScript 检查通过。
- 原生 ACL、主动配对、旧凭据拒绝、启停和旧注册项所有权清理通过；清理测试使用独立临时 HKCU 键，未更改真实 Chrome 注册项。
- 子代理、Source、远程 Agent、设置及会话回归使用实际 Electron/React 组件和隔离服务夹具，不调用真实模型。涵盖发送/停止、工具渲染、队列引导、历史装载、会话隔离、主题和中英文窄栏布局。
- 表格重算包装器：13 项通过；真实 LibreOffice/openpyxl 集成因本机缺少依赖跳过。
- 设置布局测试有一次在断言完成后的 Electron 退出阶段出现原生句柄异常，单独重跑正常退出；没有把异常退出当作通过。
- Git 差异空白检查及本轮变更的密钥模式检查通过；签名私钥、机器专属身份配置、日志和打包输出不纳入提交。
