# 对话提取和 Fork

右键侧栏会话选择「提取对话」，或按 `Ctrl+Shift+E`（可在快捷键设置修改）。标题和描述均可留空；只有两项都填写后，才能永久保存并进入输入框的 `@` 列表。

默认选择最近 5 个已提交的轮次。已有完整轮次总结优先于最终回复；中途检查点保留总结及检查点之后的可见回复。无总结时采用用户消息和可见 Agent 回复，不导出隐藏推理或系统指令。超过预算时，按整轮从最早的轮次开始缩小默认范围，不静默截断单条消息。

下拉框选择「选择」后返回来源会话，用户气泡右侧和 Agent 回复左侧出现圆形选择框；一个 Agent 轮次作为一个回复选择单元。「完成选择」返回保存弹窗。切换到其他会话时可以通过顶部栏返回来源会话。

## 保存与引用

- **另存为 Markdown**：通过系统保存对话框选择位置，写入独立 `.md` 文件。
- **临时保存**：正文在本地临时 `.md` 文件中，数据库只记录元数据；任一主窗口会话的输入框显示灯泡。30 秒内点击可插入一次，灯泡随即消失。未使用的提取到期删除；已插入的文件在本次应用运行期间保留。退出应用删除所有临时提取，异常退出后在下次启动清理。
- **永久保存**：数据库保存标题、描述、来源会话与选择键，不复制会话正文。通过 `@` 选择，或点击引用标签时，按需生成 Markdown。来源会话删除或选中内容被替换后会明确报错。
- **拖拽会话**：从侧栏拖到会话区，按默认规则插入引用，支持会话引用自己。引用固定当时选中的轮次，不会把后续包含它自己的消息再次纳入；可跨应用重启使用，不加入永久提取的 `@` 列表。

引用在输入框和消息中显示为可点击的标签；点击后在右侧打开 Markdown 预览。发送时解析为实际文件路径和来源资料说明，由 Agent 的文件读取工具读取，仍遵守当前工具权限。引用材料不会变成宿主指令。

## Token 预算

预算为当前模型配置的上下文窗口除以 4，涵盖标题、描述、Markdown 标记和正文。当前使用 UTF-8 字节数作为保守文本 Token 上界，界面明确标记其估算方法；不是模型计费 Token 的精确分词结果。这样也能处理自定义模型和中英文混排，不会使用 `字符数 / 4` 低估中文内容。选择、保存和发送时均检查；多个提取在同一条消息中发送时合计也不能超过该限额。

元数据位于应用数据目录的 `conversation-extracts/extracts.sqlite`，按需文件位于其 `files` 子目录。文件随退出清理，永久/拖拽引用可以从来源重新生成。

## Fork

右键「Fork 会话」新建独立会话并切换过去，复制当时已提交的消息、总结、替换历史与工具结果记录。正在生成的轮次不在复制范围内。新会话使用独立会话身份与工作区设置，不继承执行中的任务、权限请求、Goal、子代理关系、提供方响应缓存或源工作区的撤销操作；不会重新执行工具。历史附件仍引用原文件。

## 验证

`npm run test:conversation-extraction` 构建运行时和 Electron，并运行后台数据/预算/引用/Fork 测试及 Electron 组件交互测试。后者覆盖右键、快捷键、默认选择、手动选择、三个保存入口、灯泡跨会话使用和过期、`@` 标签、Markdown 预览、拖拽、自引用和 Fork。
