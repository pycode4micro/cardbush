# 个人助手 assistant

[English](PERSONAL_ASSISTANT.en.md) · [简体中文](PERSONAL_ASSISTANT.md)

个人助手是侧栏「新会话」下方灯泡打开的持续会话，默认名称为 `assistant`。它负责交流、发布资料和派发任务；后台任务使用现有 Agent 的模型、工具和权限。本文描述当前主分支，实际安装包可能尚未包含这些更新。

## 开始使用

1. 在「设置 → 模型管理」配置文字模型，再点击侧栏灯泡。文字交流不需要配置实时语音服务。
2. 点击标题栏「助手设置」修改名称、角色与交流方式，或选择头像。头像支持 PNG、JPG、WebP，最大 8 MB，仅保存在本机；可恢复默认灯泡。角色修改用于后续文字请求，正在进行的通话保持启动时的人设，下次接通采用新设置。
3. 默认执行主机是「本地」。需要远程执行时，点击标题栏「连接 SSH / 管理主机」，按 [Agent 服务指南](AGENT_SERVICES.md)接入已部署的服务，再在「执行主机」中选择它。仅保存一个 SSH 项目不能代替独立 Agent 服务。
4. 输入问题或任务；模型选择、文件选择、拖放、图片粘贴和浏览器引用复用普通输入框。语音配置见[实时通话](REALTIME_VOICE.md)与[本地语音](LOCAL_VOICE_MODELS.md)。

助手复用会话标题栏、右侧栏、工作摘要和回到底部按钮。精简输入框沿用保存的宽度、发送后位置和输出方向；从右侧栏的「输入」入口切回时，草稿和附件保留。灯泡反映连接、聆听、说话、静音、后台执行和错误状态；减少动画设置会关闭相应动画。

浏览器 `@` 引用在输入框、已发送消息和浮动会话中显示为可点击的标签标题，保留原始标签身份，不显示编码后的长地址；已有消息同样适用。浮动会话的回复气泡在深浅主题下都有独立底色和边界。

等待文字回复时，消息流和浮动会话显示三点动态气泡；完成、失败或停止后收起。旁边的「停止等待」停止本次助手回复，不取消已派发的独立任务。无正文、输出截断或网络失败会明确提示，可通过「重试回复」使用当前模型配置继续，保留原消息和已执行工具的回执，不重复添加用户消息。重启后未完成的用户消息也提供重试入口。

文字生成继承模型的最大输出配置，未填写时为 128,000 tokens，包含思考额度。无模型事件超过 120 秒视为传输停滞，沿用最多三次的统一重试预算；持续收到思考或输出时刷新计时。停止后的迟到响应不能写入页面或新一轮上下文。

默认底部输入布局中，短回复自动滚动到完整可见的位置；回复超过可用阅读高度时，从开头展示，并尽量保留本轮较短的提问。同一轮分多条发布时保留开头的阅读位置。手动上翻会暂停跟随，点击回到底部可查看末尾，再次发送会恢复自动定位。

## 页面显示与任务

右键文字消息可回复、引用或复制；先选中文字可只引用或复制选区。引用在输入框上方独立显示，发送后可点击定位原消息，失败重试保留同一引用。快捷表情与更多表情可添加、替换或取消，随本地会话保存；表情不会触发模型请求或变成聊天正文。重置上下文同时清除引用历史与表情。键盘可用 Shift+F10 打开菜单、方向键选择、Esc 关闭。

| 内容或操作 | 行为 |
| --- | --- |
| 文字消息、录音转文字后发送 | 显示在助手页面，进入持续对话上下文。 |
| 助手文字最终回复 | 显示正文；页面不展开思考、工具参数或执行 loop。 |
| `page_write` 发布内容 | 将 Markdown 写入当前助手会话，适合资料、例子、链接与任务结果；不创建外部网页。 |
| 通话双方的转写 | 作为内部上下文保留，不逐句显示、触发气泡动画或拉动页面。普通会话仍显示自己的通话转写。 |
| 后台任务气泡 | 显示意图和实际状态，点击打开原子会话的执行详情；完成后保留入口。 |

需要执行的任务由助手派发到子会话，立即获得任务 ID，用户可在执行期间继续交流。接收回执表示已受理；完成、失败和停止以实际任务状态为准。后续补充交给同一子会话，已结束的任务可继续，结果反馈由应用异步送回助手。

本地子任务继承助手已授权的 CardBush 内置标签页及浏览器选择，能直接操作 `@` 引用的原页面。再次引用标签并向原任务补充指导或继续执行时，会同步新的选择；未新增引用时保留子任务自己的页面选择。页面关闭或重启后的旧引用只在浏览器操作时报告失效，不阻止其他任务派发，也不自动转到 Chrome / Edge。远程子任务不继承本机网页授权。

助手通过 `subagent`、`tasks`、Team 和 `page_write` 派发、续做、读取结果并发布回复。`subagent({prompt})` 创建任务，`subagent({task_id,prompt})` 向运行中的任务追加指导或在原子会话和主机继续已完成任务。实时语音保留共用协议层的派发、即时状态、分页读取和页面发布入口。执行工具仍属于子 Agent，继续遵循其权限。语音层没有额外的派发确认，但不能通过口头授权改变工具禁用或宿主策略。

文字对话及「转写 + Agent + 朗读」链路还直接提供以下管理能力，无需先派出子任务：

- `schedule_task`：创建、查询、修改、暂停、恢复、删除、手动运行或停止定时计划。复用「定时任务」页面和调度器，仅管理当前 assistant 会话创建的计划；不开放操作系统定时器。计划保存的是完整模型、工作区、执行工具和权限配置，定时运行使用独立会话，不继承聊天历史。因此必须保存自包含的任务说明；保存成功不代表任务已执行。应用关闭期间不会执行定时工作。
- `scheduled_results`：分页读取定时任务收件箱和指定运行结果。读取不自动标记已读，也不代表重新运行任务。
- `search_skills`、`list_plugin_commands`、`mcp_search`：查询当前 Runtime 的可用能力，遵守禁用工具、Skill 范围和插件可见性。查询不执行插件或授予权限，也不能据此推断远程员工具备同样能力。
- `update_task_plan`：维护父会话总体计划，在标题栏「工作摘要」中展示，并在刷新、重启后恢复。子任务继续维护自身进度，不会覆盖总体计划。显式重置 assistant 会清除总体计划，但保留已保存的定时任务。

上述工具使用既有参数校验、宿主权限及插件 Hook，并保存真实执行回执；需要人工处理的权限请求显示在输入框上方，可允许一次、允许本会话、拒绝或取消。禁用工具不会因进入 assistant 而重新开放，终端、文件写入和通用插件调用仍交给子 Agent。

Assistant 的文字模型请求遇到临时连接中断、限流或可恢复服务错误时，当前模型轮最多尝试 3 次，复用 Runtime 的退避延迟（通常为 1 秒、2 秒，并尊重服务端 Retry-After）。页面显示重试状态和原因；成功后清除，耗尽后保留输入并显示错误。重试保留同一份上下文与工具回执，不重新派发已经成功执行的工具。重置 Assistant 或退出应用会取消等待。实时语音连接仍使用独立的重连机制。

## 执行主机与附件

助手交流、模型与历史留在本地主机，不再提供独立 Agents 聊天或执行主机选择器。远程服务在 Team 中注册为子 Agent，由助手通过现有子 Agent / Team 工具装配执行。职责与服务身份固定，继续原任务仍回到原宿主，见[远程子 Agent 协议](SUBAGENT_REMOTE_PROTOCOL.zh-CN.md)。

附件保留本地预览引用。向远程 worker 提供文件需显式传输或使用服务器已有资源，不自动复制父历史，也不把本机路径当作服务器路径。图片输入遵循所选模型与视觉设置。

浏览器引用提供上下文，不自动授权页面。远程图形能力需独立部署[可选 Linux 桌面](../deploy/agent/README.md)，不会获得用户本机的桌面控制权。

## 通话与静音

独立麦克风按钮常驻，点击开始转写时播放提示音并变蓝，再次点击结束，文字只插入输入框草稿；有草稿时按钮也不会换位。长按主发送／操作按钮进入通话，底部显示简洁线条声波，主按钮转为停止通话。通话使用「设置 → 语音 → 语音通话」保存的模式，实时语音与「转写 + Agent + 朗读」的配置各有用途。本地识别或 TTS 模型不改变实时语音服务的声音和判停。

返回文字、切换页面、打开设置、最小化或隐藏到托盘都会保留当前通话及其归属。在助手页使用输入框通话控件，离开后使用浮动胶囊。短暂网络断线有有限恢复流程；未识别的声音可能需要重说，详见[通话恢复](REALTIME_VOICE.md#与原有语音的关系)。

右键侧栏助手入口可分别控制「麦克风静音」和「播报静音」，设置保存供下次使用。麦克风静音停止上传；播报静音仅控制本地音量，模型回复与后台任务继续。普通会话不继承助手的静音设置。挂断释放收音和播放资源，不取消已派发任务。

通话需要桌面运行，不代表应用退出后仍持续聆听。本地任务遵循 Runtime 的停止与恢复规则；独立服务在自身运行期间继续执行已接收的远端任务。

## 上下文与重置

助手页面内容、内部通话转写和后台回执通过独立会话日志记录，不占用正在执行的普通文字 Turn 序号。会话日志按 JSONL 保存；文字上下文过长时由所选文字模型整理摘要，保留原始日志。实时语音另有由系统安全存储加密的 `voice-history` 和后台压缩，用于同一会话的后续通话。原始通话音频不归档。

文字模型另有仅主机可写的 `.model.jsonl` 交换日志，按实际顺序保留助手消息、工具调用、工具回执、推理与供应商回放数据。下一轮及重启后追加新输入，不再从页面气泡重建并删掉工具历史；`page_write` 的页面投影不会重复进入模型上下文，内部交换也不进入页面或语音展示。旧日志迁移只能保留当时实际存下来的内容，不能恢复已经丢弃的工具交换。进程中断而未保存回执的调用会标为结果未知，恢复时不会自动重做副作用。

助手压缩沿用普通会话的 token 预算，按 `contextWindowTokens`、工具定义、推理和回执计算压力，不再套用固定 20,000 字符阈值。压缩仅替换完整交换组成的前缀；原文保留在日志中，检查点跨重启恢复。用户主动改模型、视觉能力、角色或实际触发压缩仍可能改变供应商输入前缀，不能承诺固定的缓存命中率。

这些摘要用于当前助手回忆，与跨会话的 `summary_for_user` 习惯和下一步预测分开；不会因启用助手就自动打开个性化记忆。模型整理上下文及生成口述任务总结会消耗文字模型用量。重置上下文会同时清空页面日志与模型交换日志。

右键助手入口选择「重置上下文」，确认后会结束当前助手通话，清空页面消息、内部转写、压缩摘要及加密语音记忆。名称、头像、角色、执行主机和静音设置保留。该操作无法撤销；旧请求和通话的迟到写入不会进入新上下文。

重置不删除其他会话，也不取消已派发子任务；任务保留在各自子会话，助手的新页面不重新展示旧任务气泡。需要停止任务时从对应执行详情处理。

## 实现与验证入口

- `src/features/assistant`：入口、设置、页面、共享输入框和执行主机选择。
- `packages/bush-runtime/src/assistantConversation.ts`、`conversationJournal.ts` 与 `assistantModelHistory.ts`：持续交流、页面/模型日志、受限工具和后台完成反馈。
- `src/backend/realtimeAgent.ts` 与 `packages/bush-runtime/src/realtimeAgent.ts`：复用现有请求准备、子会话调度和任务归属。
- `electron/realtimeVoiceService.ts` 与 `src/features/voice`：应用级通话、音频、恢复和语音上下文维护。

在仓库根目录运行 `npm run test:assistant`、`npm run test:voice-realtime`；录音与原有串联通话使用 `npm run test:voice`。测试使用模拟 Provider、回环服务与隔离桌面窗口，覆盖持久化、幂等、任务归属、附件、重置、后台通话和压缩，不代表真实服务听感或真实 SSH 网络已经验收。整体边界见[当前架构](ARCHITECTURE.md)。
