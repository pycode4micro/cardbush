# 最终回复信号与个性化记忆

## 使用方式

设置 → 个性化 → 个性化记忆提供两个独立开关，默认关闭：

- **记住并参考用户习惯**：允许 Agent 保存、搜索有依据的长期偏好。
- **预测下一步行为**：允许保存、检索、认领和消耗可能的后续需求。

设置从下一轮生效。本机和远程请求使用同一套客户端开关；数据库保存在各自运行端，同一运行端跨 turn、跨会话共享，不向其他运行端自动复制私人记忆。子代理继承当前状态，用户继续子会话时使用新的设置。关闭暂停对应的读写，不删除既有记忆。

工具始终在目录中。状态通过内部 user 消息 `individuation_preference` 追加，工具执行以宿主构造的请求 metadata 为准，模型无法通过工具参数或文字打开能力。工具定义、系统前缀不随开关变化，已存在的历史不改写；上下文压缩后保留当前状态。Source、文件交付和普通引用继续走原链路。

## 工具约定

`summary_for_user({ habits?, predictions?, consumed_prediction_ids? })`

- 稳定系统规则要求在最终答复前调用；没有要保存的内容时传 `{}`，不要求重复一遍最终答复。
- 成功返回 `status: "ok", final_response: true`，以及实际记录的 ID、当前能力状态。持久化失败返回 `storage_status: "unavailable"`，仍允许继续输出最终答复。
- 仅关闭的字段被忽略：例如允许预测、关闭习惯时，只保存预测。全关时不打开或创建数据库。
- 与其他独立工具并行执行，不截断同批工具，也不直接结束 turn。

`check_habit({ query?, limit?, claim_prediction_ids?, release_prediction_ids? })`

- 按文本子串搜索（支持中文）；空 query 返回最近记录。最多每类 20 条，默认 10 条。关闭的类别不返回内容。
- 记录携带来源会话、turn 和更新时间。习惯和预测都是历史模型笔记，不是新的用户指令。
- 预测包含自然语言 trigger、action、reason；模型将后续用户输入与 trigger 比较，再决定是否执行。没有后台定时执行器，也不会因此获得额外操作权限。
- 行动前先认领 ID，只有 `claimed_prediction_ids` 返回该 ID 才能执行；完成后通过 `summary_for_user` 标为已消耗。

## 存储与恢复

每个运行端使用 `dataRoot/personalization.sqlite`，按需加载 Node 内置 SQLite。短事务原子完成写入、认领及消费，连接在操作后关闭。

桌面内置 Electron 的 SQLite 已实测可用。独立 Agent 服务启用记忆需要可用的 `node:sqlite`：Node 22.13+ 的 LTS 版本无需实验开关；旧的 22.12 需要 `--experimental-sqlite`。这是个性化存储的要求，关闭功能不受影响。参见 [Node 官方说明](https://nodejs.org/download/release/latest-jod/docs/api/sqlite.html)。

- 习惯按稳定 key 更新，附带用户语境依据；不会自动导入完整聊天历史。
- 预测按稳定 key 更新待处理记录；保留中的已认领、已消耗记录不会被同 key 写入重新激活。需要新的后续事件时使用新 key。
- 预测默认 30 天到期，可设置 1–90 天；未认领的到期记录在启用预测的操作中清理。每类保留最近最多 1000 条，最多同时认领 100 条。
- 认领状态不会因崩溃或超时自动重新触发。后续同一会话需核实执行结果：已完成则消费，确认未执行才释放并重新认领；其他会话不能抢占。
- 取消在写入前检查。数据库不可用不阻塞最终回复，但会明确告诉模型没有保存成功。
- 本数据库不属于临时日志缓存。工具调用本身仍保留在既有会话/执行记录中；关闭指不读写个性化数据库，不是删除聊天历史。

## 渲染与生命周期

Runtime 只认可当前 turn 的真实成功执行记录，给下一次普通模型响应的 assistant segment 附加 `finalResponse: true`。客户端立即按最终答复展示，但继续保留流式输入和停止能力；任务真正结束仍由 terminal/done 处理。

如果模型随后又发起工具调用，Runtime 撤销该响应的终轮展示意图，恢复过程展示，后续文本继续输出。新用户引导会作废旧的终轮意图。模型漏调、工具失败或旧客户端不认识该字段时，原有 done 收尾仍可工作。

## 验证

`npm run test:individuation` 覆盖真实 SQLite 持久化、默认关闭、独立开关、跨会话检索、并发认领、重复消费、过期、取消、失败降级、并行工具、done 前最终展示、继续调用工具时的降级、缓存前缀稳定和压缩恢复。还运行现有 Source、流式与会话生命周期回归。
