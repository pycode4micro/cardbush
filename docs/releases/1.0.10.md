# CardBush 1.0.10

## 简体中文

源码版本 `1.0.10` 对应 MSIX 包版本 `1.0.10.0`，包含当前工作区的创作、文件预览和交互修复。

- 创作、Markdown 预览和对话中的目录链接采用一致的标题匹配规则，支持中文、编码后的锚点和重复标题；创作中支持同文件及跨 Markdown 文件定位。
- 创作中的引用式链接可直接打开。修改引用地址会同步更新链接，编辑及撤销保留引用关系；文档首次载入不再进入撤销历史。
- 创作中的 AI 流式写入使用展示动画。浏览、按钮操作和链接跳转不会取消动画，实际手动编辑仍保护已保存内容。
- 文件预览支持选区提问，聊天气泡隐藏用于定位文件、选区和编辑动作的内部上下文。
- 保留独立目录下的打包启动验证及正式运行依赖检查，防止开发环境掩盖 Runtime 缺失依赖。

已知验证限制：完整预览套件中的大文本容器高度断言仍未通过。链接交互、创作编辑回归与该项独立记录；本版本不宣称完成所有预览场景的验收。

本地生成的 MSIX 用于 Microsoft Store 上传，由商店签名和认证。实际打包检查、解包启动结果和待验收项目见产物目录中的 `msix-build-report.json` 与 `packaged-smoke-report.json`。

## English

Source version `1.0.10` maps to MSIX version `1.0.10.0` and includes the current Create, file preview and interaction fixes.

- Create, Markdown previews and conversations share heading anchor rules, including Chinese, encoded fragments and duplicate headings. Create also retains fragments when following Markdown file links.
- Reference links are interactive; definition edits and undo keep their destinations synchronized. Initial document loading is excluded from undo history.
- AI writing is a visual preview. Navigation and toolbar interactions leave it running, while actual manual edits protect committed content.
- Preview selections can supply editing context without displaying internal file and selection metadata in chat bubbles.
- Production dependency checks and startup tests outside the source checkout remain part of packaging.

Known validation limitation: the broader preview suite still has a failing large-text container-height assertion. Passing link and Create regressions do not constitute acceptance of every preview scenario.

The local MSIX is a Store submission artifact awaiting Microsoft signing and certification. See the artifact's `msix-build-report.json` and `packaged-smoke-report.json` for packaging checks, extracted-app startup results and pending acceptance checks.
