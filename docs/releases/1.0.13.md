# npm release 1.0.13

[English](1.0.13.md) · [简体中文](1.0.13.zh-CN.md)

Published to the public npm registry on **October 28, 2026 at 14:17 UTC**. This is the Agent + CLI package, not a desktop installer or Microsoft Store submission. Install with `npm install -g cardbush@1.0.13`; see the [installation guide](../INSTALLATION.md) for update and uninstall behavior.

## Source and scope

The package was built from base commit [`318ffdc7`](https://github.com/pycode4micro/cardbush/commit/318ffdc7b2f1e3d7eb1768eee129de782c7ffd0a), with the release version and npm/deployment documentation updates. It contains the Agent service, local terminal client, internal runtime packages and bundled plugin assets. Browser Use, command sandboxing and optional conversion tools still depend on the target host.

The release includes the source fixes accumulated after 1.0.12, including portable MCP manifests, package-time plugin preparation and sandbox/distribution fixes. Desktop input and voice changes at that source revision do not turn the npm package into an Electron app.

The later removal of standalone Agents chats, `cardbush worker` registration and experimental `subagent-remote-proton` support are **not included in 1.0.13**. Current-source guides describe that later migration; use a matching build of both ends to test it.

## Verification recorded at publication

- Installed outside the repository on Windows; all 11 bundled workspaces and native assets were checked.
- Authenticated service chat, bundled MCP discovery and independent local CLI chat passed with a **local mock model**. These are architecture checks, not a paid-provider quality evaluation.
- An anonymous registry download matched the tested tarball, including its SHA-512 integrity. The recorded tarball size was 16,574,410 bytes.
- Registry version metadata and the `latest` tag were checked after publication. Tags may move with later releases; the [version-specific npm page](https://www.npmjs.com/package/cardbush/v/1.0.13) identifies this release.

Release receipts remain in the maintainer's ignored `release/npm-1.0.13-20261028/` directory. They are not application data and are not bundled into the package.
