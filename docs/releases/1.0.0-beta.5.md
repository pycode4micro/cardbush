# CardBush 1.0.0-beta.5

## 简体中文

### 版本对齐

- 当前源码版本统一为 `1.0.0-beta.5`，同步应用元数据、npm 锁文件、中英文 README 和当前架构说明。
- 开发运行及后续 EXE / AppImage 构建的“关于”和“复制环境信息”使用源码版本；MSIX 继续由身份文件提供独立的四段版本，当前本机配置为 `1.0.5.0`。
- 维护者已确认 Beta 5 MSIX 上传至 Partner Center。上传不代表认证通过，也不代表对应 EXE / AppImage 已发布。
- 下一版计划为 `1.0.0-beta.6`，当前源码尚未切换到 Beta 6。

### 安装与升级

EXE / AppImage 在 `v1.0.0-beta.5` 标签发布流程完成后提供，文件名分别为 `CardBush-1.0.0-beta.5-windows-x64.exe` 和 `CardBush-1.0.0-beta.5-linux-x86_64.AppImage`。已公开的安装包以[发行版页面](https://github.com/pycode4micro/cardbush/releases)为准。

本次版本对齐不修改此前生成或上传的安装包。具体文件、哈希及提交身份仅保留在私有发布记录，公开流程与脱敏验证见 [MSIX 发布说明](../MSIX_STORE_RELEASE.md)。历史验证仍只对应原始构建。后续 MSIX 更新需先核对 Partner Center 已用版本，再递增身份文件中的版本；Beta 名称不会自动转换成 Store 版本号。

## English

### Version alignment

- The current source version is `1.0.0-beta.5`, synchronized across application metadata, the npm lockfile, both READMEs and the current architecture document.
- Development and subsequent EXE / AppImage builds use the source version in About and Copy environment. MSIX retains its independent four-part identity version; the current local configuration is `1.0.5.0`.
- The maintainer confirms that the Beta 5 MSIX has been uploaded to Partner Center. This does not establish certification approval or publication of EXE / AppImage installers.
- The next planned version is `1.0.0-beta.6`; the source has not switched to Beta 6.

### Installation and upgrade

The `v1.0.0-beta.5` release workflow produces `CardBush-1.0.0-beta.5-windows-x64.exe` and `CardBush-1.0.0-beta.5-linux-x86_64.AppImage` after validation. Check the [Releases page](https://github.com/pycode4micro/cardbush/releases) for published installers.

This version alignment does not modify previously generated or uploaded installers. Exact artifacts, hashes and submission identities stay in private release records; see the [MSIX release guide](../MSIX_STORE_RELEASE.md) for the public workflow and redacted validation. Historical evidence still refers only to the original build. Before the next MSIX update, check versions already used in Partner Center and increment the identity version explicitly; beta names are not automatically converted into Store versions.
