# CardBush 1.0.15 candidate

[English](1.0.15.md) · [简体中文](1.0.15.zh-CN.md)

Prepared on November 6, 2026 for the Agent + CLI npm package (`1.0.15`) and Microsoft Store x64 MSIX (`1.0.15.0`). Neither channel is published by building these artifacts. This candidate follows the published npm 1.0.14 and incorporates the subsequent main-branch changes through `a75d4d4f` plus release preparation.

## Changes since 1.0.14

- Update Electron and build/network dependencies to patched releases, with a scoped minimatch override and package-filter regression coverage. See [dependency maintenance](../DEPENDENCY_SECURITY.en.md).
- Connect desktop conversations, Assistant and CLI sessions to configurable generic Webhook bridges. Preserve message/file provenance, restore model bindings before execution, and discover bridge tools within their source scope. Saved bindings and live connections are displayed separately.
- Unify App and CLI browser connection consent. Once a connection is approved it covers cross-site navigation; conversation-owned tabs, private tabs and restricted debugger operations remain isolated. Restore integrated-browser availability after restart without importing old tab grants.
- Fix inspector start-page navigation, back/forward shortcuts and mouse buttons according to focus. Release unlocked pages when their conversation is deleted, reject late callbacks for deleted conversations, and share frequent-site updates across start pages.
- Separate slash commands from resource mentions in desktop and CLI. Correct bold formatting beside Chinese punctuation, wrapped heading width and draft attachment placement. Forward immediate guidance to interrupt child-agent reasoning.
- Scope cancellation to the owning canvas presentation, realtime voice picker and Your Friends dialogs so child pickers and dialogs cannot dismiss an outer window.
- Split Your Friends UI into its own feature chunk while retaining its loading behavior and entry animation, keeping production scripts within the existing size budget.
- Improve Runtime startup ordering, calendar recovery, Windows CLI MCP startup isolation, and error-code propagation. Deliver longer reports as files with a concise chat result.
- Refine the desktop Your Friends preview with sequential onboarding, theme-aware circular entry and model-assisted HTML appearance generation. Appearance generation uses the configured model when requested. The event-driven digital twin runtime, automatic habit learning and autonomous event execution remain future integration work; archived demos are not the shipped runtime.

## Upgrade and validation

- npm requires Node.js 24 and npm 10 or later. Before publication, install the verified local `cardbush-1.0.15.tgz`; `@latest` still selects the public release. Restart CLI and idle services after updating, and use matching builds for remote workers.
- Reload existing unpacked Chrome/Edge extensions from the new distribution before testing its browser connection flow. Keep user workspaces and independent browser profiles intact.
- The MSIX is an unsigned Microsoft Store submission artifact. Confirm the highest used Partner Center version, including drafts/flights, before upload. Store signing, installed-package tests and Windows App Certification Kit results are separate from extraction and runtime smoke checks.
- Build and test results, exact package hashes and local identity information belong in ignored release output directories. A successful source test does not establish installed-MSIX or Linux compatibility; record each validation against the actual candidate artifact.

See [npm packaging](../NPM_AGENT.en.md) and [MSIX preparation](../MSIX_STORE_RELEASE.md) for commands and acceptance requirements. The preparation does not publish npm, submit to the Store or create a GitHub release.
