# CardBush 1.0.17

[English](1.0.17.md) · [简体中文](1.0.17.zh-CN.md)

This build targets the Windows x64 Microsoft Store package (1.0.17.0) and the Agent + CLI npm package (1.0.17).

- Open the storage inventory in Settings under Data & maintenance to see how much space conversations, attachments, registered subagents and installed runtimes use. Cleanup preserves saved definitions, task recovery state and attachments still in use.
- Assistant maintains long conversation context in batches while idle and retains original records for retrieval. Pending replies can incorporate newer facts about the same task before they are sent.
- Improved Windows window activation and control release. If Windows declines to activate a window, you can bring it forward from the prompt. Input still checks which window is active.
- Home media retains playback state across navigation. Plugin installation, updates and removal give clearer feedback, and the Web interface supports layer editing.
- Webhook maintenance can compact old delivered records while retaining receipts and retry state. Remote Agent questions show when the connection is offline.
