# CardBush 1.0.11

## 简体中文

源码版本 `1.0.11` 对应 MSIX 包版本 `1.0.11.0`，包含从主分支同步的工作流编辑、工具执行和聊天交互更新。

- 创作和 Team 流程复用普通会话及输入框，首次发送时才创建会话，历史记录保留正确的工作区归属。
- Team 支持拖动节点、连接依赖、自动布局和历史运行快照，保存时校验流程版本。
- 精简模型接收的工具定义和 MCP 管理查询结果，保留按需加载完整信息，并记录工具定义用量及可验证的失败原因。
- 区分等待用户、后台任务和前置步骤，减少被动等待导致的提醒；优化首次发送、长内容粘贴和输入框布局。
- 调整执行过程显示、补充豆包模型图标，统一图片的复制文件操作。

本版本沿用生产依赖检查和源码仓库外的打包启动验证。实际构建、解包启动及待验收项目以产物目录中的 `msix-build-report.json` 和 `packaged-smoke-report.json` 为准。1.0.10 中记录的大文本预览高度问题尚未确认修复，本次打包不代表完整预览套件已通过。

MSIX 用于 Microsoft Store 上传，仍需由商店签名与认证；本地产物不是已签名的分发安装包。

## English

Source version `1.0.11` maps to MSIX version `1.0.11.0` and includes the workflow editing, tool execution and chat interaction updates synchronized from the main branch.

- Create and Team reuse the regular conversation and composer, creating sessions on first submission and retaining the correct workspace association.
- Team supports node dragging, dependency connections, automatic layout and historical run snapshots, with version checks when saving workflows.
- Model-facing tool definitions and MCP management observations are more compact, with details available on demand and diagnostics for definition usage and verified failure facts.
- User, background and prerequisite waits are distinguished to reduce passive-wait notifications. First submission, long pasted content and composer layout are refined.
- Process controls, Doubao model icons and image file-copy actions are updated.

Production dependency checks and extracted-app startup outside the source checkout remain part of packaging. The artifact's `msix-build-report.json` and `packaged-smoke-report.json` record actual validation and pending acceptance checks. The large-text preview height issue documented in 1.0.10 has not been confirmed fixed; packaging does not imply the entire preview suite passed.

The MSIX is a Store submission artifact awaiting Microsoft signing and certification, not a signed distribution installer.
