## 简体中文

Windows EXE 与 Linux AppImage 同步更新，均从 `v1.0.0-beta.3` 源码标签构建。

- 修复引导消息在发送中、排队阶段临时跑到此前回复上方的问题；迟到的入队回执不会再把已生效的引导改回“已排队”。
- 插件更新前先停止并等待旧 MCP 服务退出，再替换目录，解决 Windows 下运行中的插件导致 `EBUSY` 的问题。保留配置、凭证和插件数据；任务占用时明确提示，更新失败时恢复原启用状态。
- 改善流式回复节奏、滚动定位、编辑器焦点及 MCP 应用恢复。
- 修复自动滚动与工具详情折叠重叠时，浏览器滚动锚点偶发无法恢复的问题。
- 包含 Beta 2 之后的自动化调度、日历导入、审查界面、执行历史、上下文压缩和缓存维护更新。
- 更新窗口菜单的发布回归检查，并纳入插件更新、回滚、占用保护和真实运行时服务释放测试。

下载 `CardBush-1.0.0-beta.3-windows-x64.exe` 或 `CardBush-1.0.0-beta.3-linux-x86_64.AppImage`。SHA-256 校验文件和成品启动报告随包提供。发布流程在两个平台执行回归测试及实际成品启动检查，Windows 另验证安装和卸载。

## English

The Windows EXE and Linux AppImage are both built from the `v1.0.0-beta.3` source tag.

- Pending and queued guidance stays after preceding assistant output during streaming. A late enqueue receipt no longer changes applied guidance back to queued.
- Plugin updates stop and await the old MCP service before replacing its directory, addressing Windows `EBUSY` failures. Configuration, credentials and plugin data are preserved; busy tasks block replacement, and failures restore the previous enabled state.
- Improved streamed reply pacing, scroll positioning, editor focus and MCP app recovery.
- Fixed native scroll anchoring occasionally remaining disabled when automatic scrolling overlaps a tool disclosure toggle.
- Includes automation scheduling, calendar import, review UI, execution history, context compaction and cache maintenance changes since Beta 2.
- Updated window-menu release checks and added coverage for plugin replacement, rollback, busy-task protection and real runtime service teardown.

Download `CardBush-1.0.0-beta.3-windows-x64.exe` or `CardBush-1.0.0-beta.3-linux-x86_64.AppImage`. SHA-256 checksums and packaged startup reports are attached. The release workflow runs regression and packaged startup checks on both platforms, plus Windows installation and uninstallation checks.
