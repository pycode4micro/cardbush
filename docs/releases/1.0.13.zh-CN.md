# npm 1.0.13 发布记录

[English](1.0.13.md) · [简体中文](1.0.13.zh-CN.md)

已于 **2026 年 10 月 28 日 14:17 UTC** 发布到公开 npm 仓库。这是 Agent + CLI 包，不是桌面安装包或 Microsoft Store 提交。安装命令为 `npm install -g cardbush@1.0.13`；更新与卸载行为见[安装指南](../INSTALLATION.zh-CN.md)。

## 来源与范围

发布包基于提交 [`318ffdc7`](https://github.com/pycode4micro/cardbush/commit/318ffdc7b2f1e3d7eb1768eee129de782c7ffd0a)，附带发布版本号和 npm/部署文档更新。包含 Agent 服务、本机终端客户端、内部 Runtime 包和内置插件资源。Browser Use、命令沙箱和可选文档转换工具仍取决于目标宿主环境。

本版带入 1.0.12 之后累积的源码修复，包括可移植 MCP 清单、打包前插件准备，以及沙箱和发行相关修复。同一源码版本的桌面输入框与语音更新不会让 npm 包变成 Electron 应用。

后续取消独立 Agents 会话、`cardbush worker` 注册和实验性的 `subagent-remote-proton` 支持**不在 1.0.13 中**。当前源码指南描述了这些后续迁移，测试时需要两端使用相匹配的新构建。

## 发布时的验证

- 在 Windows 上脱离仓库安装，检查全部 11 个内置 workspace 与原生资源。
- 带鉴权的服务对话、内置 MCP 发现和独立本机 CLI 对话使用**本地模拟模型**通过。这是架构验证，不是付费模型质量评测。
- 匿名下载的 registry 包与已测试 tarball 一致，包含 SHA-512 完整性核验；记录的包大小为 16,574,410 字节。
- 发布后确认版本元数据和 `latest` 标签。后续版本可能移动标签；[npm 固定版本页面](https://www.npmjs.com/package/cardbush/v/1.0.13)对应此发布。

发布回执保存在维护者本机被忽略的 `release/npm-1.0.13-20261028/` 目录，不属于应用数据，也不随 npm 包分发。
