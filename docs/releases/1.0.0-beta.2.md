## 简体中文

Windows EXE 与 Linux AppImage 同步更新，均从 `v1.0.0-beta.2` 源码标签构建。

- 内置「视觉」技能先读取当前应用主题，再生成趋势图、BI 指标和交互图表；明确要求图例切换、数值查看等操作具备实际事件处理。
- 对话中的可视化自然融入主题，隐藏滚动条；长内容限制初始高度，优先完整展示第一张子图，并提供展开与收起。
- HTML 文件修改后自动刷新预览，保留展开状态和阅读位置；历史文件引用也可展示当前版本。
- 修复 Linux HTML 预览的文件协议，保留中文及特殊字符路径和相对脚本、样式加载。
- 子 agent 内部回传不再显示成用户消息，兼容旧记录。子任务和查看图像在工具列表下一行显示紧凑执行预览，可打开详情。
- 引导消息不再提前展示终轮文件改动汇总，只有停止或正常完成时展示。
- 关闭右侧最后一个标签后自动收起侧栏，并缩小边缘感应区。
- 包含此前的插件生命周期、MCP 工具加载、插件导航状态与 Windows 图标修复。

下载 `CardBush-1.0.0-beta.2-windows-x64.exe` 或 `CardBush-1.0.0-beta.2-linux-x86_64.AppImage`。SHA-256 校验文件和成品启动报告随包提供。发布流程在两个平台执行回归测试及实际成品启动检查，Windows 另验证安装和卸载。

## English

The Windows EXE and Linux AppImage are both built from the `v1.0.0-beta.2` source tag.

- The bundled visualization skill reads the current application theme before generating charts and BI views, and requires working event handlers for advertised interactions.
- Inline visualizations blend into the conversation theme with hidden scrollbars, bounded initial height, complete first-chart folding, and expand/collapse controls.
- HTML previews refresh when their source changes while retaining expansion and reading position. Historical file references can display the current file version.
- Fixed native file URLs for Linux HTML previews, including Unicode and special-character filenames and relative scripts and styles.
- Internal subagent results no longer appear as user messages, including older records. Subagent and image tools have compact execution previews below the tool list with access to details.
- Guidance no longer prematurely displays the final file-change summary; stopping or normal completion triggers that summary.
- Closing the last inspector tab collapses the panel, and the edge activation area is smaller.
- Includes earlier plugin lifecycle, MCP tool loading, plugin navigation state and Windows icon fixes.

Download `CardBush-1.0.0-beta.2-windows-x64.exe` or `CardBush-1.0.0-beta.2-linux-x86_64.AppImage`. SHA-256 checksums and packaged startup reports are attached. The release workflow runs regression and packaged startup checks on both platforms, plus Windows installation and uninstallation checks.
