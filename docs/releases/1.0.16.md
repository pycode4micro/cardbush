# CardBush 1.0.16

[English](1.0.16.md) · [简体中文](1.0.16.zh-CN.md)

This build targets the Windows x64 Microsoft Store package (1.0.16.0) and the Agent + CLI npm package (1.0.16).

- Reorder and resize built-in Home sections, embed websites and add interactive HTML components. Open Components from Explore to edit the layout.
- Return to your previous reading position on Home, Explore and other visited pages. Plugin management keeps its navigation available on subpages.
- Toggle the floating Assistant from the profile menu or system tray, or close it from its context menu. Closing preserves unsent drafts and releases the window when idle. Background events read only the component catalog they need.
- Assistant can search MCP servers, skills and local plugins with `search_plugins`. Install and update Python or Node.js on demand for plugins.
