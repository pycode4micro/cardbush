## 简体中文

Windows EXE 与 Linux AppImage 均从 `v1.0.0-beta.4` 标签构建。发布流程在双平台回归、成品启动及校验和检查全部通过后公开安装包，Windows 另外验证安装与卸载。

### 本次更新

- 加入独立 Node.js Agent 服务，支持 HTTP / HTTPS 和 SSH 直连接入。服务器独立保存模型、插件、项目、会话与任务队列；桌面断开后已接收的任务继续运行。
- 本地与远端复用对话、输入框、模型选择、设置和预览组件。改善会话切换、重连、发送确认、图片附件清理、远端图片读取和消息编辑重跑。
- 加入 SSH 项目，支持通过同一工作区工具访问远端文件、搜索和命令；无需在项目主机安装 CardBush 服务。
- 应用中心集中提供插件、定时和设置入口，支持拖拽固定／排序快捷方式、应用网址、Windows 本地应用快捷方式及 `@` 应用引用。只有明确提供操作页面的插件显示为应用。
- 页面前进后退覆盖会话、插件、设置与日历；改善主题色、悬浮快捷键提示、侧栏动画、窄窗口布局及内置浏览器切回后的输入焦点。
- 权限统一为「申请批准／完全访问」。设置支持检测与手动安装命令沙盒：Windows AppContainer、Linux bubblewrap；安装后可用时默认启用，并保留用户和管理员的选择。
- 批量加载 MCP 工具定义、精简重复返回，支持归档结果关键词检索、执行历史 locator、任务计划查询／增量修改、文件搜索上下文和行号／版本锚定编辑。
- 长时间终端任务支持完成通知，工具状态使用简短动作说明；修复历史记录与终态不同步导致的持续“处理中”显示。
- 改善输出截断、上下文压缩、恢复和缓存连续性；压缩说明要求保留相关技能约束。用户消息携带固定的时间／时区快照，音视频操作默认保留源文件。
- 内置 Agent 部署与 Blender 原创视频预演技能；增加可选的离线中国／美国显示日历。显示日历不会自行创建提醒或自动化。
- 更新跨平台回归用例、Windows 沙盒短路径处理、安装检查与界面测试，并同步当前架构和部署文档，移除两份过时的根目录分析报告。

### 安装与升级

下载 `CardBush-1.0.0-beta.4-windows-x64.exe` 或 `CardBush-1.0.0-beta.4-linux-x86_64.AppImage`。SHA-256 校验文件和成品启动报告随包提供。仅提供 x64 桌面安装包。

桌面安装包不会自动更新独立 Agent 服务。要使用完整的远端对话、插件市场和新权限能力，请按[服务部署说明](https://github.com/pycode4micro/cardbush/blob/v1.0.0-beta.4/docs/AGENT_SERVICES.md)更新服务与内置技能，保留原数据目录、访问令牌和用户配置。执行中断的任务不会在重启后自动重复执行。

Linux 沙盒受主机内核、账号和 bubblewrap 可用性影响；命令沙盒不覆盖全部 MCP、插件或浏览器操作。云 Agent 不继承本机桌面操控能力。应用中心当前提供应用入口，不是通用应用部署或多协议编排引擎。

## English

The Windows EXE and Linux AppImage are built from the same `v1.0.0-beta.4` tag. Installers are published only after both platforms pass regression, packaged startup and checksum checks; Windows also checks installation and uninstallation.

### Changes

- Independent Node.js Agent services with HTTP/HTTPS or direct SSH connections. Each service owns its models, plugins, projects, sessions and queue; accepted tasks continue after the desktop disconnects.
- Shared local/remote conversation, composer, model selection, settings and preview components. Improved session switching, reconnects, submission acknowledgement, image clearing/loading and edit-and-rerun behavior.
- SSH workspaces for remote files, search and commands through the existing workspace tools, without installing a CardBush service on the project host.
- An App Center for plugins, automation and settings, with draggable pinned shortcuts, application URLs, Windows application shortcuts and `@` application references. Plugins appear as applications only when they explicitly provide an operable page.
- Back/forward navigation across conversations, plugins, settings and calendars; improved theme colors, shortcut tooltips, sidebar transitions, narrow layouts and input focus after embedded-browser use.
- Two permission modes: Ask for approval and Full access. Settings detect command sandbox support and offer explicit installation: AppContainer on Windows and bubblewrap on Linux. Available installations are enabled by default, while preserving user and administrator choices.
- Batched MCP schema loading and compact results; keyword search in archived results, execution-history locators, plan queries/patches, search context lines and line/version-anchored file edits.
- Completion notifications for long-running terminal tasks and concise tool activity titles. Fixed historical/terminal state mismatches that could leave completed work appearing active.
- Improved output-limit recovery, context compaction and cache continuity. Compaction instructions retain relevant skill constraints; user messages carry a fixed date/time-zone snapshot, and media edits preserve source files by default.
- Bundled Agent deployment and Blender video previsualization skills, plus optional offline Chinese/US display calendars. Display calendars do not create reminders or automations.
- Updated platform regression fixtures, Windows sandbox staging paths, installer/UI checks and architecture/deployment documentation; removed two obsolete root analysis reports.

### Installation and upgrade

Download `CardBush-1.0.0-beta.4-windows-x64.exe` or `CardBush-1.0.0-beta.4-linux-x86_64.AppImage`. SHA-256 checksums and packaged startup reports are attached. Desktop packages are x64 only.

Updating the desktop does not update independent Agent services. Follow the [service deployment guide](https://github.com/pycode4micro/cardbush/blob/v1.0.0-beta.4/docs/AGENT_SERVICES.md) to update the service and bundled skills while preserving its data directory, token and configuration. Interrupted running tasks are not automatically replayed after restart.

Linux command isolation depends on host kernel/account support and bubblewrap availability; it does not cover every MCP, plugin or browser action. Remote Agents do not inherit desktop-control capabilities. The App Center provides application entry points, not a general application deployment or orchestration engine.
