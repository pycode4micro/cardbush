# CardBush 1.0.15 候选版本

[English](1.0.15.md) · [简体中文](1.0.15.zh-CN.md)

于 2026 年 11 月 6 日准备 Agent + CLI npm 包（`1.0.15`）及 Microsoft Store x64 MSIX（`1.0.15.0`）。构建产物不会自动发布到任何渠道。本候选版本接续已发布的 npm 1.0.14，包含此后 main 分支截至 `a75d4d4f` 的变更及发布准备。

## 相对 1.0.14 的变更

- 更新 Electron 及构建／网络依赖的安全修订版本，定向覆盖 minimatch，并增加打包文件过滤回归。详见[依赖维护](../DEPENDENCY_SECURITY.md)。
- 将桌面会话、Assistant 和 CLI 接入可配置的通用 Webhook 桥。保留消息和文件来源，执行前恢复模型绑定，按来源范围发现桥接工具，并区分已保存的绑定与实时连接状态。
- 统一 App 与 CLI 的浏览器连接确认。批准连接后覆盖跨站导航，继续隔离会话所属标签、私人标签及受限调试操作。内置浏览器重启后恢复可用性，不恢复旧标签授权。
- 修复检查面板起始页导航，以及按焦点分发的前进／后退快捷键和鼠标侧键。删除会话时释放未锁定页面，拒绝已删除会话的迟到回调，多个起始页共享常用网站更新。
- 区分桌面和 CLI 中的斜杠命令与资源引用。修复中文标点旁的粗体、标题换行宽度和草稿附件布局；立即指导会传递给子 Agent 并中断其推理。
- 隔离创作画布演示、实时语音选择器和 Your Friends 弹窗的取消事件，避免子弹窗或选择器的事件关闭外层窗口。
- 将 Your Friends 界面代码拆为独立功能包，维持现有加载方式和进入动画，并满足生产脚本体积约束。
- 改进 Runtime 启动顺序、日历恢复、Windows CLI 的 MCP 启动隔离及错误码传递。较长报告通过文件交付，在聊天中提供简洁结论。
- 完善桌面 Your Friends 预览：顺序初始化交流、跟随主题的圆形进入动画，以及模型辅助生成 HTML 形象。用户请求生成形象时会使用配置的模型。事件驱动的数字分身运行时、自动 habit 学习和自主事件执行仍待接入；归档演示不等于已集成的运行时。

## 更新与验证

- npm 要求 Node.js 24、npm 10 或更高版本。发布前安装经过验证的本地 `cardbush-1.0.15.tgz`；`@latest` 仍指向公开版本。更新后重启 CLI 及已空闲的服务，远程 worker 两端使用相匹配的构建。
- 验证浏览器连接流程前，从新发行包重新加载已有的 Chrome/Edge 解压扩展。保留用户工作区及独立浏览器配置。
- MSIX 是尚未签名的 Microsoft Store 提交产物。上传前确认 Partner Center 已用最高版本，包括草稿和 flights。商店签名、已安装包验证和 Windows App Certification Kit 检查，与解包及运行时 smoke 分别记录。
- 构建和测试结果、准确包哈希及本机身份保存在被忽略的发布目录。源码测试通过不代表已验证安装后的 MSIX 或 Linux；各项验收都应对应实际候选产物。

命令和验收要求见 [npm 打包](../NPM_AGENT.md)与 [MSIX 准备](../MSIX_STORE_RELEASE.zh-CN.md)。本次准备不自动上传 npm、提交商店或创建 GitHub Release。
