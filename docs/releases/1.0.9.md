# CardBush 1.0.9

## 简体中文

源码版本 `1.0.9` 对应 MSIX 包版本 `1.0.9.0`，修复商店版 `1.0.8.0` 的 Runtime 启动故障。

- 将主进程使用的 `@cardbush/chrome-mcp` 加入正式运行依赖。旧包遗漏该依赖，安装后启动失败，点击重试无法补齐文件。
- 打包检查现在同时核对主进程实际使用的 ESM 导入、CommonJS 加载和动态导入，阻止未声明的运行依赖进入发布包。
- 启动验证将打包应用复制到源码仓库外，以独立工作目录和用户数据运行，并清除 Node 开发搜索路径及启动参数，避免借用开发依赖而误判通过。失败的启动报告也会保留。

旧版故障已在独立目录复现。新版 MSIX 的解包副本已在仓库外通过 Runtime、插件刷新、终端、搜索及资源检查，相关打包回归共 12 项通过。商店签名后的安装、升级与完整功能验证仍属于发布验收。

## English

Source version `1.0.9` maps to MSIX version `1.0.9.0` and fixes the Runtime startup failure in Store version `1.0.8.0`.

- Declares `@cardbush/chrome-mcp` as a production dependency. The previous package omitted this dependency; retrying startup cannot restore missing files.
- Checks the packaged host's actual ESM imports, CommonJS loads and dynamic imports against its production dependencies.
- Copies the packaged application outside the source checkout for startup validation, using an independent working directory and profile without Node development search paths or launch overrides. Failed startup reports are retained as well.

The old failure was reproduced outside the checkout. The extracted replacement MSIX passed Runtime, plugin refresh, terminal, search and asset checks outside the checkout, alongside 12 packaging regressions. Store-signed installation, upgrade and full feature validation remain release acceptance steps.
