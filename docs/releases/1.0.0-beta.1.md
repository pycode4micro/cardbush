## 简体中文

CardBush 首个 Windows / Linux 桌面 Beta 安装包。

- Windows 10/11、Intel / AMD 64 位：下载 `CardBush-1.0.0-beta.1-windows-x64.exe`。
- Linux x86-64：下载 `CardBush-1.0.0-beta.1-linux-x86_64.AppImage`，赋予执行权限后启动；验证环境为 Ubuntu 22.04。
- 首次使用请在「设置 → 模型管理」配置模型服务和 API 密钥。

统一了应用内终端、Shell 查找、平台能力与原生资源路径。修复 Windows 长短路径混用、深目录 Git 快照、被占用文件的搜索降级、文件地址解析和后台命令中文输出问题。修复系统开启「减少动画」时图片预览首帧空白的问题。README 提供中英文切换、下载入口及平台能力说明。原创代码采用 Apache-2.0。

发布流程在 Windows 和 Linux 上执行类型检查、核心回归与对抗测试、Electron 界面测试、实际安装包启动检查；Windows 另验证安装和卸载。模型传输测试使用本地模拟 HTTP 服务，不需要付费 API。

Beta 安装包未进行代码签名。Linux 暂不提供 Windows 电脑操控、Chrome 原生连接器和 Windows Job Objects 等价的 CPU/内存限制；对话、文件、MCP、内置浏览器与原生 Shell 可用。外部插件仍需满足各自的系统要求。Windows 卸载保留用户数据。

## English

The first CardBush desktop beta for Windows and Linux.

- Windows 10/11 on Intel / AMD 64-bit: download `CardBush-1.0.0-beta.1-windows-x64.exe`.
- Linux x86-64: download `CardBush-1.0.0-beta.1-linux-x86_64.AppImage`, make it executable and run it. Validated on Ubuntu 22.04.
- Configure your model provider and API key in Settings → Model Management before starting a conversation.

Shared platform adapters now handle embedded terminals, Shell discovery, native resources and capability reporting. This release fixes Windows short-path aliases, Git snapshots in deep directories, search fallback with locked files, native file URLs and Unicode output from background commands. Image previews no longer begin with blank frames when the system prefers reduced motion. The README includes language switching, download links and a platform feature matrix. Original CardBush code is licensed under Apache-2.0.

Both platforms pass type checks, core regression and adversarial tests, Electron UI tests and packaged startup checks before publication. Windows also passes installation and uninstallation checks. Provider transport tests use local mock HTTP servers, without paid API calls.

These beta installers are unsigned. Linux does not yet provide Windows computer use, the Chrome native connector or equivalent Job Object CPU/memory limits. Chat, files, MCP, the integrated browser and native Shell are available. External plugins retain their own platform requirements. Uninstalling on Windows preserves user data.
