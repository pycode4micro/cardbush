# CardBush 1.0.17

[English](1.0.17.md) · [简体中文](1.0.17.zh-CN.md)

本次构建面向 Windows x64 Microsoft Store（1.0.17.0）和 Agent + CLI npm 包（1.0.17）。

- 在「设置 → 数据与维护」查看存储清单，了解会话、附件、子 Agent 注册和已安装运行环境的占用。清理会保留已保存的定义、用于恢复的任务状态和仍有引用的附件。
- Assistant 在空闲时分批维护长对话上下文，原始历史可以回读。同一任务的新状态到达时，尚未发送的回复会使用更新后的事实。
- 改进 Windows 窗口激活和控制释放。系统拒绝激活时可手动切回目标窗口，后续输入仍会检查实际前台窗口。
- 跨页面导航保留主页媒体播放状态。改进插件安装、更新和移除的反馈，并为 Web 提供图层编辑。
- Webhook 保留回执和重试所需的状态，可压缩已投递的旧记录。远程 Agent 问题在连接不可用时会显示离线状态。
