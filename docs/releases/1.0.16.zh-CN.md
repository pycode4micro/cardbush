# CardBush 1.0.16

[English](1.0.16.md) · [简体中文](1.0.16.zh-CN.md)

本次构建面向 Windows x64 Microsoft Store（1.0.16.0）和 Agent + CLI npm 包（1.0.16）。

- 主页支持调整原生区块的顺序和大小，也可以添加嵌入网页及交互式 HTML 组件。从「探索」打开「组件」可进入布局编辑。
- 返回主页、探索或其他已访问页面时，可以从之前的阅读位置继续。插件管理的子页面保留导航入口。
- 在个人菜单或托盘切换悬浮助手，也可以从助手右键菜单关闭。关闭时保留未发送的草稿，空闲时释放窗口。后台事件只读取所需的组件目录。
- Assistant 通过 `search_plugins` 搜索 MCP、技能和本机插件。插件所需的 Python 和 Node.js 运行环境支持按需安装和更新。
