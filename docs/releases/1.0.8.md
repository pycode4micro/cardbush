# CardBush 1.0.8

## 简体中文

当前源码版本为 `1.0.8`，对应 MSIX 包版本 `1.0.8.0`，不再使用 Beta 后缀。维护者已确认此前 MSIX 版本为 `1.0.7`；本页记录下一版的改动，安装包是否可用以商店和 [Releases 页面](https://github.com/pycode4micro/cardbush/releases)为准。

### 主要改动

- 更新浏览器工作区、会话交互、通知与文档预览；内置 XLSX、PPTX、Word 和 PDF 插件支持文档生成、渐进读取及验证。
- 修复主会话未选过内置浏览器时，子代理新开的网页被放入隐藏工作区的问题；修正标签页列表中锁定、静音与关闭按钮挤到下一行的布局。
- 子代理新建的内置页面会向各级父会话回传精确控制权限，父会话可直接读取和操作同一页面。未绑定的父会话首次读取使用 CardBush，已有浏览器与页面选择保持不变；关闭共享页面时同步清理授权。
- 修复 assistant 模型控件误读普通会话选择的问题；继承型子代理续派时同步当前父会话的模型与参数，并更新执行配置供界面正确显示。
- assistant 文字与转写语音主对话接入现有本地习惯/预测记忆，支持自动相关召回、按需补查、保存和纠错，沿用全局开关。后台任务结果不作为新的用户记忆证据，重试、压缩和重置保留引用去重及失效检查；原生实时语音直连通道仍独立。
- 修复输入框渐变遮罩盖住滚动条的问题；assistant 新回复按最新气泡自动展示，短回复完整可见、长回复从开头阅读，普通点击不会中断跟随，并补充可按需开启的滚动定位日志。
- 修复 Browser Use 在页面滚动后的点击命中坐标；改进 MCP 工具搜索排序，翻页改用绑定查询与会话的游标，避免换查询后漏过结果。
- 浏览器面板开关和会话分栏调整保留底部或当前阅读位置；移除思考区下方自动插入的文件产物卡片、音视频播放器，保留正文引用、产物菜单和计划看板。
- 缩小会话正文中的图片预览；连续图片合并为主图与竖向缩略图，切换时保持展示区域稳定，支持本地、远端和文件 Memo 图片引用。
- 修复记忆总结时状态与列表反复清空造成的闪烁。事件整理和习惯压缩改用独立、可自定义的 10,000 token 默认阈值，每阶段全量总结一次；重复命中的事件可转为习惯。总结继承模型输出额度与思考强度，按实际有效用量拒绝越压越大的结果，保留原记录、历史和用户修改，失败原因可展开查看。
- Responses 输入计数与生成能力分别记录。计数端点不支持时使用本地估算，不再因此关闭原生工具、工具图片或续轮能力；生成兼容处理只在明确拒绝实际使用的能力时发生，且不会重放已经开始输出的请求。
- 更新 Electron 42、MCP SDK 2、sharp 及受影响的传递依赖；针对尚未更新依赖约束的上游包采用限定范围的版本覆盖，增加代理下载、命令启动、Excel 条件格式及 PPT 图片的回归验证。
- MCP OAuth 客户端密钥绑定可信授权服务器。凭据保留并校验 issuer，阻止把既有密钥或令牌交给另一个授权服务器。
- 开发环境、CI、Agent Docker 镜像及 Node 类型定义统一到 Node.js 24 LTS，整理依赖安装脚本策略和维护文档。

### 升级要求与验证

- 源码安装和独立 Agent 服务需要 Node.js 24 LTS、npm 10 及以上。Windows 终端不会因 `.nvmrc` 自动切换 Node，需要先选择正确版本。参见[依赖维护说明](../DEPENDENCY_SECURITY.md)。
- 使用 OAuth 客户端密钥的直连服务需在高级配置填写服务商提供的 `expectedIssuer`；缺少 issuer 标记的旧凭据需重新登录，不自动补写绑定。参见[插件连接说明](../PLUGIN_COMPATIBILITY.md)。
- 本次依赖与 OAuth 改动在 Windows / Node 24 下完成安装、构建、类型检查及 178 项自动回归，并通过真实 Electron OAuth 和插件设置界面验证。审计当时全量与生产依赖的 `npm audit` 均为 0 项已知漏洞；这些结果不代表未来审计或所有发布渠道已通过验证。
- EXE / AppImage 的预期文件名为 `CardBush-1.0.8-windows-x64.exe` 和 `CardBush-1.0.8-linux-x86_64.AppImage`；MSIX 为 `CardBush-1.0.8.0-x64.msix`。各渠道仍需通过对应发布门禁。`v1.0.8` 标签按正式版本发布，不固定标记为预发布；后续版本继续同步源码三段版本与 MSIX 四段版本，并确认 Store 版本尚未使用。

## English

The source version is `1.0.8`, with corresponding MSIX package version `1.0.8.0` and no beta suffix. The maintainer confirms the preceding MSIX version was `1.0.7`. These notes describe the next version; check the Store and [Releases page](https://github.com/pycode4micro/cardbush/releases) for available installers.

### Changes

- Updated browser workspaces, conversation interactions, notifications and document previews. Built-in XLSX, PPTX, Word and PDF plugins support authoring, progressive inspection and validation.
- Fixed child agents opening integrated browser pages in a hidden workspace when the parent had not selected a browser. Fixed lock, mute and close controls wrapping onto a second line in the tab list.
- Returned exact control grants for newly created integrated pages to each verified ancestor conversation, allowing parents to read and operate the same page. Unbound parents use CardBush on first access; existing browser and page choices are preserved. Closing a shared page clears its grants across conversations.
- Fixed assistant model controls reading an ordinary conversation's selection. Inherited child continuations now use the parent's current model and parameters, with the latest execution configuration saved for accurate UI display.
- Connected assistant text and transcribed-voice conversations to the existing local habit/prediction store and settings, with relevant recall, explicit lookup, saving and corrections. Background task results cannot create user-memory evidence; retries, compaction and resets preserve deduplication and invalidation. Native realtime audio remains a separate channel.
- Kept composer backdrops clear of native scrollbars. New assistant bubbles are revealed immediately: short replies fit in view, long replies start at their beginning, and ordinary clicks no longer disable following. Added opt-in scroll positioning diagnostics.
- Fixed Browser Use hit-test coordinates after scrolling. Improved MCP tool search ranking and bound pagination cursors to their query and conversation so changing a query cannot silently skip results.
- Browser panel changes and conversation resizing preserve bottom-follow or the current reading position. Removed automatically inserted file cards and media players below thinking, while keeping authored references, the artifacts menu and task plans.
- Reduced inline image previews and grouped consecutive images into a stable main image with vertical thumbnails, supporting local, remote and file memo references.
- Fixed memory settings flicker by retaining status and record nodes during polling. Events and habits now have separate, configurable thresholds, each defaulting to 10,000 tokens. Each stage summarizes its full snapshot once; repeatedly verified events can become habits. Consolidation inherits the selected output allowance and reasoning effort, rejects growth in actual active memory, and preserves originals, history and user edits with inspectable failure reasons.
- Responses input counting and generation have separate capability records. An unsupported counting endpoint falls back to local estimates without disabling native tools, tool images or continuation. Generation compatibility changes require an explicit rejection of a capability actually used in the request, and do not replay requests after output begins.
- Updated Electron 42, MCP SDK 2, sharp and affected transitive dependencies. Scoped overrides cover upstream packages whose dependency ranges still select vulnerable versions, with regression checks for proxy downloads, command launch, Excel conditional formatting and PPT images.
- Bound MCP OAuth client secrets to a trusted authorization server. Stored credentials retain and validate their issuer rather than being reassigned to a newly discovered server.
- Standardized development, CI, Agent Docker images and Node typings on Node.js 24 LTS, and documented dependency maintenance and install-script policy.

### Upgrade and validation

- Source installations and independent Agent services require Node.js 24 LTS and npm 10 or later. `.nvmrc` does not automatically switch an existing Windows terminal; select Node 24 before installing. See [dependency maintenance](../DEPENDENCY_SECURITY.md).
- Direct OAuth connections using a client secret must configure the provider's trusted `expectedIssuer`. Old credentials without an issuer require fresh sign-in. See [plugin connections](../PLUGIN_COMPATIBILITY.md).
- The dependency and OAuth changes passed installation, build, type checking and 178 automated checks on Windows / Node 24, plus real Electron OAuth and plugin-settings UI validation. Full and production-only npm audits reported zero known vulnerabilities at verification time. These checks do not establish future audit results or validation of all release channels.
- Expected installers are `CardBush-1.0.8-windows-x64.exe`, `CardBush-1.0.8-linux-x86_64.AppImage` and `CardBush-1.0.8.0-x64.msix`, subject to their release gates. The `v1.0.8` tag publishes as a regular release rather than always being marked as a prerelease. Future updates should keep the three-part source and four-part MSIX versions aligned and confirm the Store version has not already been used.
