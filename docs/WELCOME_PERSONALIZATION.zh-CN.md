# 欢迎建议与星光字标

[English](WELCOME_PERSONALIZATION.md) · [简体中文](WELCOME_PERSONALIZATION.zh-CN.md)

空会话显示 canvas 绘制的 `cardbush` 字标和三个可编辑起始建议。选择建议只填入并聚焦输入框，不发送消息，也不替换非空草稿。

## 历史边界

`runtime.list_user_prompts` 是只读日志投影。欢迎页读取普通用户会话过去滚动七天的消息，按消息时间筛选，排除隐藏／子会话、内部与具名续接、自动化提示及已被替代的用户消息。使用已有 `composerReferenceContent` 元数据去除显式引用展开内容；工具／助手载荷与附件正文不经过此接口。

请求最多返回 1,200 条近期提示（协议上限 2,000），每条最多 4,000 字符并标明截断，限制大历史的传输与排序成本。直接读取规范日志，不建立经验库、不修改历史、不把建议注入模型或调用 LLM。进入欢迎页及窗口恢复可见时刷新，最短间隔一分钟。

## 排序与回退

排序采用抽取方式：中英文分句，每个独立提示的词项只计一次，根据词频与近期程度排序完整原句，再降低重复话题权重。排除常见填充词、代码、引用块、路径、URL 和引用标记。ICU 将中文切为单字时用相邻字符恢复，不使用项目专用词典。建议保留来源语言与措辞，不由模型改写。历史缺失、不可用或不足时，用明确标记的通用建议补齐三个位置。

## 渲染

四角星、菱形和圆点组成文字蒙版。本地日期时间决定平滑变化的配色，浅色主题另有对比度规则；`d`、`b` 的粒子在深色保持白色强调，在浅色保持近黑色，包括移动过程中。

鼠标接近会散开星点，按住主键会聚拢，离开后重新组成文字，不影响触摸滚动。DPR 上限 2、动画上限 30 fps；隐藏／离屏暂停，减少动态效果时绘制静态图，卸载清除观察器、动画和定时器。窄窗口纵向排列建议，保持输入框可用。

切换项目／任务模式时，在同一次 React 事件内确定目标会话，不先清空选择并挂载中间空输入框再由 effect 找草稿。已有不同范围的草稿独立保存；缺少范围时只准备一个内存草稿。

## 验证

- `node --test scripts/test-welcome-suggestions.mjs`：规范历史、时间、替代关系、频率／多样性、重试、来源污染、回退和配色。
- `node scripts/run-welcome-ui.mjs`：隔离 React/Chromium 的历史读取、草稿／焦点、主题／窄屏、鼠标重组、减少动画、可见性和卸载清理。无产品配置或模型调用，截图在 `tmp/welcome-redesign-*.png`。
- 历史测试前构建协议和 Runtime。
