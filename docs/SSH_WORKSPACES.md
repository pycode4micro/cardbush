# SSH 项目

[English](SSH_WORKSPACES.en.md) · [简体中文](SSH_WORKSPACES.md)

SSH 是 CardBush 桌面端的工作区能力，不需要安装插件或远程 CardBush 服务。

## 使用入口

- 设置 → SSH 连接：保存多个主机，支持 SSH Agent、私钥文件和密码认证。
- 添加项目和新会话默认页的位置选择器：选择本地文件夹或 SSH 连接，再浏览/输入远程目录。同一连接可以保存多个项目。
- 侧栏 SSH 项目菜单 → 选择远程目录：确认后保存目标项目；当前会话属于原项目时同步切换其实际工作区，否则打开目标项目的新会话草稿。取消或切换失败时保留原绑定。
- 输入 `@`：选择已保存的 SSH 连接，确认目录后切换实际执行位置并添加引用。
- 会话顶部不再显示“独立工作区”按钮。已有项目间的拖拽切换继续使用原工作区切换机制。

连接首次使用时需要在连接管理中测试并确认主机指纹。已保存指纹发生变化时拒绝连接，不自动更新信任。密码及私钥口令通过 Electron safeStorage 存储；私钥保留在用户指定的本地文件中。主机、端口或用户名改变需要新增连接，防止已有项目被重定向。

## 执行范围

当前支持 Linux/POSIX 与 Windows OpenSSH 主机。POSIX 终端需要 `/bin/sh` 和支持 `--wait` 的 `setsid`（util-linux）；Windows 终端必须有可通过 `pwsh` 启动的 PowerShell 7，不支持 Windows PowerShell 5。两者都需要 SFTP；内容搜索需要 `rg`，Git 功能需要 Git，替换已有文件需要服务端原子重命名能力。依赖不会自动安装。执行前探测实际系统和 Shell，不匹配时拒绝发送用户命令；SFTP-only 账号仍可使用界面的目录浏览和文件预览，但无法执行模型的终端任务。跳板机、SSH config 导入、交互式 MFA 和远程插件运行仍不属于此入口。

工作区使用 `ssh://连接ID/目录` 身份保存在项目和会话中，远程路径大小写保持不变。选择 SSH 工作区后，模型的工具 schemas 只保留 `terminal_exec`、`terminal_poll`、`terminal_write`、`terminal_stop` 和 `terminal_list`。文件读写、搜索、技能、插件、MCP 和其他工具不会进入普通工作回合的 schemas，本机插件钩子及快捷命令也不运行。上下文压缩由独立的维护回合处理。

所有终端操作绑定到当前选定的 SSH 主机；文件查看、搜索和修改通过该主机的 Shell 完成。工具不提供 `environment` 参数，旧调用中的本机或其他连接覆盖参数也会被拒绝。访问本机或其他主机前，用户需要切换会话的工作位置；切回本机后恢复原有工具。

省略 Shell 时使用探测到的默认值；POSIX 支持 `posix`，Windows 支持 `powershell` 和 `cmd`。Windows 路径支持 `C:\Users\name` 或 `/C:/Users/name`，`/` 仅是 SFTP 浏览根，不是执行目录。权限仍按所选主机及路径检查。终端详情不再显示额外的执行位置标识。项目 Git 操作继续跟随所选项目。

本机附件保留在本机，不自动变成远程文件；模型可见的图片像素不受影响，需要处理文件原件时须先传到目标主机。远程项目直接操作所选目录，不提供本地检查点、任务副本或本地撤回。

## 文件引用与审查

- 历史 `remember_file` 和 `remember_source` 证据继续支持本机与 SSH 文件；这些工具不在 SSH 模式的 schemas 中。本机证据使用绝对路径；远程证据使用文件工具返回的完整 `ssh://连接ID/绝对文件路径`，不把远程目录当成本机权限根。引用经过对应主机的路径权限检查，连接不可用时不会回退到本机。
- `@` 选择远程文件后保留 SSH 路径。远程图片作为文件引用交给 Agent，不伪装成本机视觉附件。SSH 会话中的 Markdown 相对路径和 POSIX 绝对路径按当前 SSH 工作区打开，Windows 绝对路径仍指本机。
- 引用可在侧栏打开文本、代码和 Markdown；文本预览最多读取前 2 MiB。通用图片/媒体资源读取上限为 8 MiB，不将远程文件无限量下载到桌面内存。Office、模型等依赖本机专用转换器的格式尚未接入 SSH 转换。
- Source 对不超过 2 MiB 的文件保存版本哈希及可选行摘录，较大文件只记录元数据。历史注释保持原始证据版本，重新查看时提示文件已变更或不可用。
- 历史远程 `write_file` / `edit_file` 的真实修改记录仍可查看，审查显示具体文件、增删行和差异。内部差异进入执行记录，不重复塞进模型的简短结果。路径保留原始大小写；权限与并发写入身份按远端系统的路径语义比较。
- 读取 `git diff`、`git diff --stat` 或历史差异不会生成新的修改记录。没有 Git 的目录也可审查文件工具的修改；分支界面显示普通提示，不再请求不存在的分支列表。
- SSH 暂不支持任务撤回，也不会自动捕获远程终端/脚本产生的修改；撤回入口禁用，运行时也拒绝误发的撤回请求。旧执行中未记录的真实差异无法凭统计数字补造。

## 运行行为

- 切换执行位置保留聊天记录和草稿，不搬动项目文件；运行中的回合、后台工具或远程终端会阻止切换。
- SSH 连接失败不会回退本地，断线不会自动重放命令。终端标记为 `disconnected` 时，远程进程可能仍存在，应重连后核对。
- 内部文件接口编辑要求当前会话先读取该文件的最新 SHA-256 版本；SSH 模型工具只提供终端，终端编辑不经过该接口。桌面进程内的同文件写入互斥，写前再次核对版本；其他客户端不受此锁约束。
- 终端按会话和连接隔离，发起命令与轮询输出分离。`terminal_list` 仅列出本会话在当前主机的终端；`terminal_poll/write/stop` 拒绝其他主机的旧句柄。切换工作位置前必须结束当前会话运行中的终端。POSIX 停止向远程进程组发送 TERM，必要时 KILL；Windows 使用所属 Job Object 管理子进程。无法确认停止时返回错误。进程归属管理不等于沙箱或权限提升。
- 退出应用时尝试停止已知远程终端并关闭 SSH 连接；外部启动或主动脱离进程组的服务不属于 CardBush 托管任务。

## 验证

`npm run test:ssh` 构建协议/Runtime/主进程并运行 SSH 协议和运行时测试。协议测试使用回环地址上的真实 SSH 握手及 SFTP/进程测试服务，不读取用户 SSH 配置、不连接外部主机。

`npm run test:ssh-ui` 在隐藏 Electron 窗口验证连接管理、指纹确认、明暗主题、窄窗口、目录浏览、失败处理、默认页/会话切换及 `@` 引用。真实服务器连通性需要用户配置连接后通过“测试”验证。

`node scripts/run-app-views-test.mjs ssh-review` 验证 SSH 文件引用点击、代码预览、修改审查及非 Git 目录和撤回入口状态。回环 SSH 测试还覆盖本机/远程混合资料引用、版本变化、大小写路径和读取限额。
