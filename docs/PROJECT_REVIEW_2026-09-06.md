## 范围限制

- 配置锁是同一 Product Host 进程内的并发保护，不是跨进程文件锁；外部编辑器或多个独立宿主同时改写同一配置不在此次保证范围内。
- 插件升级覆盖可捕获的复制/移动失败；断电或强制杀进程发生在目录交换中途的自动恢复机制尚未加入。暂存目录位于插件根目录的父目录，名称为 `.cardbush-plugin-install-*`，避免把备份当作已安装插件。
- 未对所有模型供应商发起真实付费请求，未对真实账号的外部服务执行写入。本轮没有重复操纵用户桌面进行原生 Computer Use 对抗测试；此前记录见 `COMPUTER_USE_TEST_REPORT_2026-09-05.md`。
- 通过测试不能证明不存在其他缺陷。大型组合组件和宿主入口仍使审查成本较高；本轮优先修复有证据的问题，没有展开大规模结构重写。
- 构建仍有既有的 chunk 体积提示，未作为运行失败处理。
