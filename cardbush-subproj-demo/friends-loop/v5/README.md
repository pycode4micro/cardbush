# Friends v5：真实时间、真实公开新闻的短场景测试

范围：仅服务器 42.192.59.45 上的独立目录、独立服务。用户已取消 24 小时运行，本次只观察约五分钟后的首次触发和汇报，随后结束测试。

## 用户可见预设

只有一条 habit：喜欢 NBA，每天指定北京时间看一份中文简报，最多三条，关注比赛结果、重要伤病和交易，注明原始来源及发布时间，不重复旧内容。具体时刻由初始化时的服务器真实时间加五分钟得到；无预置来源 URL、新闻正文、工作事件或检测注册。

主场景首次启动于北京时间 2026-11-04 17:33:49，habit 时刻为 17:38:49。这里发生的是用户习惯中的阅读时刻，不承诺任何比赛或新闻发布会恰好发生在五分钟后。

## 实现

沿用 v4 的三个模块与 CardBush Runtime：
- EnvironmentService 增加通用 web_search、web_read、HTTP 来源变化检测；使用真实系统时钟。
- EventRegistry 仍保存 Agent 自建的工作事件和检测条件；增加 HTTP 检测条件，不预置业务动作。
- FriendsLoop 使用真实默认模型自主发现来源、判断有无可用信息、选择工具与最终回复；无 user 角色消息。
- web-transport.py 只读取公开 HTTP 页面/Feed，校验公共地址，限制大小和超时，不携带账号凭证。搜索使用通用搜索引擎；NBA 查询与来源选择来自模型工具参数。
- 文章证据包含读取时间、来源 URL、发布时间（如源提供）、内容及版本；搜索摘要不能冒充文章证据。过期网页证据需要重新读取。
- 实际工具调用结束后，必须获得 Runtime completed 与模型终轮文本，才能形成报告；写产物不等于已汇报。

新闻数据为真实网络读取，不是模拟资料。是否足够新、来源是否支持摘要，必须结合实际回执人工复核，不能只凭队列与工具成功认定内容正确。

## 验证和停止条件

10 项基础测试验证持久检测、恢复、证据版本、真正终轮、HTTP 注册、搜索与文章证据区分。

monitor.py 只读数据库与运行状态，不给 Agent 发指令，不创建事件，不提供新闻。它在实际终轮产生后继续观察 30 秒，核验重复交付和空闲调用，再停止本 demo 服务。另有 20 分钟硬截止与 80 次请求上限，防止短实验失控。

正式 CardBush 服务 cardbush-agent-42.service 不修改。旧 v4 测试服务已停止，历史结果保留。v5 未设置开机自启。
