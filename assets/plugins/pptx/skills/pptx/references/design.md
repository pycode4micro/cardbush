# 演示文稿的设计判断

用于新稿和视觉改稿。目标是让内容有清晰的主次、适合受众并具有辨识度；这里没有默认主题或必须套用的页型。用户提供的品牌、模板和风格要求优先。

## 从参考形成方向

先理解文稿是用于演讲、阅读、提案还是教学，以及观众需要记住什么。阅读型报告可以保留较多证据；投影讲解更需要远距离可读的重点。不要把同一份文字直接套进通用卡片模板。

有图片或成品参考时，观察标题与正文的尺度关系、留白、对齐、图像占比、色彩节制和不同页面的节奏。借鉴这些关系，不照搬无关文案、品牌或装饰。只看封面不够，还要理解内容页如何组织证据。

没有指定风格时，自主选择适合内容的方向。例如，商业提案可以用编辑式排版与建筑摄影；创意介绍可以用温暖材质与细腻文字层级；技术说明可以用清楚的系统图和证据图表。它们是可能的选择，不是主题到配色的固定映射。换一个强调色或背景色不足以构成新方向。

完整新稿先制作能检验方向的关键页，例如封面与一张有真实内容密度的页面。查看效果后再扩展整稿，避免先复制大量同一种版式。关键页数量由任务决定；除非用户要求评审，不为这个步骤新增确认流程。

## 让每页为内容服务

每页应有明确的阅读入口和主要结论。标题的大小、位置、分行与周围留白共同建立层级；英文眉题、页码和装饰标签只有在有用时保留。大量微小辅助文字会削弱主要信息。

选择能表达关系的构图：趋势需要时间或比较的视觉证据；流程需要清楚的顺序；案例可以由一张有意义的图片配合重点展开；核心观点也可以用有力的文字构成整页。不要把不同内容都装进三栏、圆角框或“标题加要点”。卡片适合确实需要分组的内容，不必禁用，也不应成为默认页型。

统一字体系统、对齐关系和强调方式，同时让页面的疏密、尺度和图文比例随叙事变化。重复用于建立识别，变化用于突出不同信息。不要为了凑变化牺牲逻辑，也不要为了整齐把每页做成一样。

字体根据参考、语言和实际可用性选择，不固定为一种字体或字号。投影页的正文需在观看距离下可读；阅读型图表可更密。拥挤时先改善表达、拆分信息或重排，再考虑缩小字体。必要证据和数据不能为了美观省略。

## 使用合适的视觉材料

照片、插图、纹理与复杂图形都可与可编辑文字并用。图像应提供情境、解释或主视觉价值；当图像更合适时，不用大量线条和圆圈拼出泛化的“科技感”。资产不足时可以选择有意设计的纯文字或原生图形构图，不需要勉强配图。

保持图像比例并有意识地裁切；文字放在清晰可读的区域。真实证据、产品界面与标识保留其含义。示意图和生成图不要伪装成真实事件照片。需要外部或生成资产时使用当前可用工具，将选定文件纳入制作输入，不假定网络地址始终可用。

文字、图表和需要继续修改的数据表尽量保持原生对象；照片本身可以作为图片。整页截图不能代替用户需要的可编辑文稿。原生图表的分类、单位、比例和来源必须能支持结论；不要把装饰图当作数据证据。

## 看成品后再判断

按 [预览指导](preview.md) 查看实际 PPTX，而非只检查代码、对象数量或自建 HTML 样稿。缩略图适合检查全稿节奏，实际页面适合检查可读性与对象关系。

判断观众是否能快速找到主要信息、画面是否服务内容、图像是否有意义，以及连续页面是否机械重复。对照用户参考检查视觉方向，而不只检查有没有越界。修改问题页后再次预览；不要仅因文件成功写出就宣称专业或已通过视觉验收。
