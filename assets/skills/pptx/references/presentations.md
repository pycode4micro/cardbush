# 演示文稿读写

本参考适用于创建 PPTX，或修改现有演示文稿。API 以当前安装版本为准：

- [python-pptx 文档](https://python-pptx.readthedocs.io/en/latest/)
- [PptxGenJS 文档](https://gitbrent.github.io/PptxGenJS/)

## 现有文件

用 `pptx.Presentation(path)` 读取文稿，检查 `slide_width`、`slide_height`、`slides`、各页 `shapes`。有 `text_frame` 的形状可读取段落与 runs；表格逐格读取，图表从数据系列读取。图片和组合形状不能用“没有文本”判定为空白页。只需要内容提取时不重新保存文件。

替换文本时保留适用的段落和 run 样式。对整个 text frame 重新赋值会重建文本结构，可能丢失局部加粗、链接和样式。复制幻灯片、复杂动画和特殊嵌入对象不属于所有库都能可靠处理的功能；先验证最小样例，必要时使用有相应能力的原生编辑器。

## 新建文稿

先确定页面尺寸，再用真实尺寸定位对象。`python-pptx` 的长度可用 `pptx.util.Inches` 或 `Cm`，字号用 `Pt`；PptxGenJS 的常用几何参数以英寸表示。不要混用坐标单位。

为每种页面结构明确内容边界、标题区域和图文间距。每页内容不同，不能仅靠固定文本框高度容纳所有段落。示意图与文字分别建模，避免把整页转成不可编辑的背景图片。

读入用户数据生成图表时，保留分类顺序、单位、缺失值含义和总计口径。图上的结论要能由其展示的数据支持。

保存到工作区的新文件后，再加载检查关键对象。文件写出成功只表明序列化成功，排版仍需渲染检查。
