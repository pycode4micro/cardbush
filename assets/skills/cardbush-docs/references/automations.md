# 定时与自动化

创建或修改任务时，使用当前实际暴露的 `schedule_task` 工具及其参数契约。只在用户要求闹钟、定时、重复执行或持续跟进时创建；查看日历、导入假日资料并不授权自动执行。

- 一次/周期定时任务使用独立执行会话，不携带来源会话的消息历史。任务提示词必须自包含：目标、输入路径、必要业务参数、时间/时区、结果交付要求。
- 来源会话提供创建时保存的运行配置，并保留跳转链接。删除来源后，独立定时任务仍按保存配置执行；来源链接显示不可用，不伪造会话。事件触发/插件唤醒依实际绑定模式处理，不把它们都理解成独立闹钟。
- 结果在“定时与自动化”的日历、未读、今天、全部结果中查看。打开执行会话可继续追问，返回来源用于追溯设定。
- 计划管理默认收起细节，展开后编辑、立即执行、暂停或删除。删除对话和删除计划是不同操作；要取消闹钟须暂停或删除计划。
- 状态只以调度器与工具返回为依据：已保存、排队、执行中、已完成、失败等不能混为一谈。导入日历不会创建或更新这些执行状态。

开发实现参考仓库 `docs/AUTOMATIONS.md` 与 `docs/AUTOMATION_INBOX.md`；不要求普通用户查阅源码。
