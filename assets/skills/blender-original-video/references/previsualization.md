# 预演与局部修改

在搭建或修改 Blender 预演时使用。具体操作依赖当前 MCP 和 Blender 版本，不固定工具名称，也不将示例镜头当作所有项目的必选步骤。

## 精度服务于控制目标

| 控制目标 | 足够的预演信息 |
| --- | --- |
| 运镜、景别、空间布局 | 地面、墙体、门洞、主体占位体、实际摄影机与路径 |
| 入画、离场、转向、围坐、人与物关系 | 占位体的整体朝向、移动轨迹、停留位置与空间距离 |
| 指领口、拉袖口、拿起道具等具体动作 | 仅确定目标位置、发生时间与文字意图；肢体动作交给视频生成模型 |
| 特定光照变化 | 对构图和叙事有影响的光源方向、明暗与变化时点 |

人物用胶囊体、圆柱或块体等无肢体占位体表达位置、尺度与朝向，只对整个占位体做位移和旋转。不添加简陋四肢，不制作骨骼绑定、行走循环、手指、手势或表情动画，避免生成模型沿用僵硬的肢体表现。即使手部接触或服装动作是核心，也只记录动作目标、时间和文字要求，写进生成提示词，并在成片中重点检查。

不需要为镜头外的布景、不可见结构或无关材质投入精细制作。产品形状直接影响构图、遮挡或动作时，保留相关轮廓和比例。

## 把镜头意图落在场景里

为当前项目保留便于理解的角色、道具、相机标识。多镜头延续同一空间和主体时，共用场景中的身份与位置事实，避免每次切镜重新猜测关系。

根据镜头需要设置相机位置、朝向或跟踪目标、焦距/视野、移动路径、速度变化和时间范围。区分角色移动、相机移动和焦距变化；它们不能仅凭“主体变大”互相替代。

以约定的画幅、帧率和时长预演。检查切点、起止状态、转弯速度、主次关系与展示时长；不要为了显得复杂而添加运镜。多空间长镜头应先验证连接关系和可通行路线。

需要细节特写时，标明特写对象和到达时点。例如“镜头看清领口”应落实为目标区域进入画面并保持可读，而不只是相机靠近人物。

## 两种输出用途

- **检查版**：按需显示俯视布局、相机路径、主体标识或时间信息，帮助用户理解并修改。
- **生成输入版**：导出实际摄影机画面，去掉编辑器界面、坐标轴、网格、路径线、选中轮廓、角色文字和其他非成片内容。使用便于判断空间的简洁材质，避免难以分辨主体与背景。

检查版不是模型输入版。多视图拼图可用于讨论，不能代替实际运镜视频。确实需要分屏成片时，再按用户设计保留分屏。

## 修改已有预演

先读取实际工程和当前版本，把反馈定位到具体对象、属性、时间范围。只改受影响的部分；若修改必然牵动其他镜头，说明具体影响。

已有工程含肢体模型或动画时保留原稿，在预演副本中用无肢体占位体表达整体轨迹，生成输入版不携带这些肢体动作。

| 用户反馈 | 优先检查与修改 |
| --- | --- |
| 镜头低一些、人物小一些 | 相机高度、位置、焦距及画面中的主体比例 |
| 转弯太急 | 相机路径与朝向曲线、速度和缓动 |
| 人物走慢一些 | 占位体沿轨迹移动的速度与时长，再检查相机跟随；自然步态通过生成提示词调整 |
| 多展示一秒领口 | 相机构图、特写时段、主体停留和相邻镜头衔接 |
| 手势僵硬、走路不自然 | 调整生成阶段的表演描述并复查成片，不在 Blender 中补建肢体动作 |
| 换衣服，镜头满意 | 保留已确认的空间和运动；更新外观绑定，必要时调整衣服轮廓 |

复用镜头时检查新主体的尺寸与动作空间，模板中的相机距离不是通用常量。保存新版本，保留原工程和已接受产物。

## 判断与证据

查看实际摄影机输出，特别是起止帧、切镜前后、转弯、遮挡和产品展示附近的连续画面。必要时用场景数据辅助检查穿插、位置和时长，但技术检查不等于创意验收。预演只验证整体走位与运镜，肢体和表情的自然度在生成成片后验证。

记录看到了什么、哪里仍不确定。检查之后导出生成输入版时，确认使用的是同一场景版本、相机、时间范围和画幅，避免把旧预演提交给生成服务。
