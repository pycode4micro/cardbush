# 生成交接与成片验收

在预演准备交给视频生成、替换素材或修订成片时使用。沿用用户选择和现有授权，不绑定特定平台、模型、固定时长或镜头数量。

## 让输入各司其职

按实际上传顺序，为需要使用的素材建立清楚的指代。没有提供或不需要的类别不必补齐。

| 输入 | 应明确的职责 |
| --- | --- |
| 干净预演视频 | 空间关系、主体轨迹、摄影机运动、构图、镜头顺序与节奏 |
| 人物参考 | 外观身份，以及用户指定由它决定的其他特征 |
| 产品或服装参考 | 款式、颜色、结构、材质等有证据的产品事实 |
| 场景与风格参考 | 场景外观、光影、氛围及允许变化的范围 |
| 音频参考 | 明确是音色、台词、音乐、节奏还是其他用途 |
| 文字 | 故事、对白、素材绑定、允许发挥的细节与必须保留的约束 |

预演中的主体标识绑定到具体人物和产品，不能靠图片顺序猜测主角。切镜后的左右位置可能变化，身份绑定仍应保持一致。

占位体的颜色与简化形状通常仅用于表达身份和运动，应在提示词中明确其用途；若其中某项本就是用户的外观设计，则按用户要求保留。

## 组织提示词

把预演已经清楚表达的运动用准确指代交给模型，重点补充它无法表达的外观、表演和声音。不要另写一套与预演冲突的镜头路线。

可按当前任务简化下面的自然语言结构，无需固定字段或冗长逐帧描述：

> 以视频1作为运镜、构图、主体动线和镜头节奏的参考。占位体A对应图片1的人物，服装采用图片2；场景外观采用图片3。保留已确认的镜头顺序和动作关系，最终画面不保留占位体、辅助标识与临时材质。对白以本提示词为准。其余表演细节在这些约束内自然完成。

音色参考存在时，将“哪个说话人使用哪个音频、仅参考音色、实际台词来自哪里、是否允许其他声音”写进真正发送给模型的提示词。用户要求固定音色时，明确不得替换或混用其他音色；多次生成分别携带绑定。提示词不能保证声音完全一致，需检查实际声音。

已有外观参考足够时直接复用；只有缺少必要信息时才制作关键帧或补充参考，不把付费生图设为所有任务的必经步骤。

## 提交与持续执行

依据当前生成工具确认素材类型、数量、时长、尺寸、角色字段和模型能力。需要上传的文件必须在执行主机可访问；远端服务不能直接使用本机磁盘路径。通过现有上传工具提供可用素材地址或资产标识。

尽量按创意的连续性组织生成。镜头列表不等于任务列表；多个切镜也可以属于一个连贯段落。只有模型限制、独立镜头制作或已确认的局部修订需要时才拆分，保留相邻状态与声音连续性。模型不支持必要运动参考时，说明限制，不能悄悄改为图片加文字并宣称控制等价。

每次提交保留采用的预演版本、输入对应关系、提示词、设置及返回任务 ID。复用插件提供的后台任务和等待能力；状态查询不创建新任务。超时或断连先检查已有任务与产物，不能把“未拿到结果”当作“未执行”。

## 对照验收并定位修改层

把成片与同版本预演对照，检查本次真正要求保留的内容：

- 空间连通、人物身份、进出方向、物体关系和遮挡。
- 景别、主体占画面比例、镜头路径、动作到达时间、切点和结束状态。
- 产品轮廓、颜色、领口、袖口、口袋、纽扣等实际要求的细节。
- 台词、说话人、音色、口型与动作配合；有声音要求时实际听取音频。
- 占位体、辅助线、临时文字、异常肢体或不应出现的物件是否残留。

抽帧可定位细节，但不能证明连续动作或声音通过。若当前环境不能查看连续视频或听音频，明确尚未验证的项目，不把文件存在、时长正确当作通过。

镜头本身不合意，修改 Blender 预演；外观不合意，调整相应素材和生成说明；预演正确而成片偏离，保留已确认预演并定位生成问题。已接受的成片范围优先保留，仅在授权范围内修订。精确文字或产品细节仍无法可靠保留时，可提出使用确定性渲染或后期合成，而不是承诺加长提示词就能解决。

## 能力依据

- [Blender Lab MCP](https://www.blender.org/lab/mcp-server/)：通过 Blender Python API 连接现有场景与模型工具调用。
- [Seedance 2.5 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)：白模参考、主体/场景素材分工、辅助信息残留和动作细度的参考资料。仅在采用此服务且需要具体细节时读取；运行时参数以当前工具与官方说明为准。
