# 数据图表、趋势与 BI

仅在交互视图包含数据图表时读取。布局、主题适配、交付和交互验证遵循 [SKILL.md](../SKILL.md)。

- 明确指标、时间范围、单位、数据来源和截止日期。真实数据、预测和模拟数据分开标示；无法获得的未来月份或缺失值留空或说明，不自行补成一条完整走势。
- 同比、环比、累计值和当期值不能混作同一口径。金额单位转换后更新轴标签；比例标清 `%`，变动差额按实际含义标为百分点。
- 时间趋势用按日期排序的折线；类别比较用条形图；多指标量纲不同则分图或清晰标注。柱状图通常从零起，折线按数据范围留余量。不要用平滑曲线制造未观测到的峰谷。
- 用可见标记或简短标注突出关键变化。悬停或点击可查看时间、系列、数值和单位，触屏和键盘也能获取同一信息；筛选或对比控件应帮助用户回答实际问题。
- 多系列趋势图需要图例切换时，将图例实现为真实按钮，绑定曲线、面积、标记和提示内容的显隐，用 `aria-pressed` 和视觉状态表达选择，并保留缩放、主题切换后的状态。宿主不会自动把图例文字变成控件；纯颜色说明不必做成开关。
- 按容器宽度重绘坐标轴；窄窗口减少刻度、换行图例或纵向排列面板，不把固定宽度 SVG 缩小到标签难读。将每张子图及其标题、图例、轴标签与控件放在同一内容单元内，让宿主在完整子图之间折叠。
- 实际点按图例、图表或筛选控件，确认可见结果与数据口径一致；检查全部轴标签、极值、缺失值和多系列联动。趋势模板 [trend.html](../assets/trend.html) 的数值是模拟数据，不能只换标题就作为真实分析交付。
