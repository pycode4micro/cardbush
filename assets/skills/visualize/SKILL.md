# 视觉

让用户在对话里直接看到数据和关系。对于走势、同比/环比、经营分析、BI 指标对比，优先判断是否需要一张可直接阅读和交互的图；有可靠数据且图表能帮助判断时，直接生成并内嵌，不等用户再次要求“画出来”。单个数字、简短列表或用户明确要求纯文字时，无须额外可视化。

## 先读取当前主题，再生成图表

每次创建或重新设计图表前，先查询当前 CardBush 的实际主题。不要根据旧截图、操作系统主题或模板的默认配色猜测，也不要先生成白底页面，再依靠外层容器修饰。

1. 用命令工具运行此 skill 目录内的 `node scripts/read_theme.mjs`（工作目录不在 skill 内时，传入脚本的绝对路径）。它优先读取 `CARDBUSH_THEME_CONTEXT_PATH` 指向的主题快照；默认安装也可从用户配置目录读取。此操作只读，不修改用户主题。
2. 读取结果中的 `theme`（实际主题）、`preference`（选择来源）、`colorScheme`、`background`、`fontFamily` 和 `tokens`。当用户选择跟随系统或自定义主题时，以实际颜色为准，不能只看主题名称。
3. 据此确定整个图表的背景、标题、正文、次要文字、网格、图例、数据系列、控件与浮层配色。初始回退值采用本次查到的颜色；正文和标注保持对比，图表强调色可从主题的信息色、强调色推导。随后按下文的宿主变量与事件适配后续主题切换。
4. 在当前主题下预览后再交付。交付前若主题已切换，重新读取并复核。读取失败时，使用当前可用的界面读取或截图工具查看 CardBush 的实际外观；仍无法确认时保持深浅主题感知、明确该项未验证，不假装已经读取主题。

## 在 CardBush 中交付

- 将完整 HTML 写入当前任务可长期保留的目录，使用真实的绝对路径。可使用原生 SVG、Canvas 或项目已有的图表库；简单图无需下载新依赖。
- 图表完成主题适配后，在 `<head>` 声明 `<meta name="cardbush:preview" content="visualization">`，启用融入对话的呈现和自适应高度。普通 HTML、旧报表保留带标题与操作栏的文件预览。不能只给仍然写死浅色背景的旧页面加声明来隐藏边框。
- 在最终回复需要显示图表的位置，单独一行输出 `![图表标题](<绝对路径/chart.html>)`。CardBush 将 HTML 图片语法渲染为可交互预览；普通 `[标题](<路径>)` 只显示文件链接。不要使用其他产品的私有可视化标记。
- 图表在助手回复完成后加载。将解释放在图表前后，保持简短；不重复整份图表数据或另附一份相同表格，除非用户需要。
- 如需起点，读取并改写 [assets/trend.html](assets/trend.html)。示例中的数值是模拟数据，必须替换为任务数据；不能只换标题就当作真实分析交付。

## 图表自然融入对话

- 以图表为主体：一个简洁标题，必要的口径、单位和来源，随后直接展示图。一般走势分析不默认添加 KPI 卡片墙、网页导航、页头横幅或层层圆角容器。用户明确需要 BI 看板时，再加入能解释问题的指标和联动。
- 页面顶层透明、无外框和阴影，宽度跟随容器。宿主在图表外提供起止分隔、选项和展开/收起入口，HTML 内不再重复这些控件。图内网格保持轻淡，重要数据突出，标题不重复出现在额外工具栏。
- 使用宿主注入的 CSS 变量：`--background`、`--foreground`、`--muted-foreground`、`--border`、`--popover`、`--popover-foreground`、`--font-sans`，以及 `--viz-series-1` 到 `--viz-series-6`。独立打开时可给变量设置随 `prefers-color-scheme` 切换的回退值；不要固定成白底网页或仅适配黑色。
- 宿主更新 `document.documentElement.dataset.cardbushTheme` 和 `color-scheme`，并发送 `cardbush:theme-change` 事件。SVG 优先直接引用 CSS 变量；Canvas 或将颜色缓存为字符串的图表库需监听此事件更新颜色，保留筛选、缩放和选中状态。
- 宿主按内容测量高度，默认预览不超过 520px（小窗口进一步缩短），超出后由宿主提供展开/收起。第一屏放主图和必要口径，补充内容放后面；HTML 自身保留完整自然排版，不写截断高度或重复折叠逻辑。展开仍有 2400px 上限，更长内容可在图内滚动或侧栏查看，必要时拆成几张有独立含义的图。避免顶层 `100vh`、固定最小页高和横向溢出。
- 图表内不显示滚动条或预留滚动条槽。用 `scrollbar-width: none` 和 `::-webkit-scrollbar { display: none; }` 隐藏滚动条，保留滚轮、触控与键盘滚动；不要用 `overflow: hidden` 把超出内容截掉。优先让内容自然撑开随对话滚动。
- 以实际容器宽度重绘坐标轴；在 320px 窄窗口减少刻度、换行图例或纵向排列面板，不把固定宽度 SVG 整体缩小到标签难读。
- 将每张子图及其标题、图例、轴标签和必要控件放在同一个 `section`、`figure` 或带 `data-chart-section` 的容器里。宿主优先在完整子图之间折叠；并排图也保持完整，不靠固定像素猜裁切点。单张图本身超过预览上限时仍可展开查看。

## 动画与滚动性能

- 有播放/暂停的 SVG、Canvas 动画，暂停时用 `cancelAnimationFrame` 真正停止循环，恢复时只启动一个循环并重置上一帧时间。只停止时间累加、却继续 `render()` 或写入相同 SVG 属性，仍会每帧触发布局和绘制，影响会话滚动。静态图表按数据、尺寸、主题或交互变化更新，不常驻逐帧循环。
- 页面隐藏时停止绘制，恢复后保留用户的暂停选择，避免按隐藏时长补跑动画；尊重 `prefers-reduced-motion`。不要为了维持离屏动画改用定时器绕过浏览器节流。
- 验证动画时实际点击暂停，确认 DOM/Canvas 更新停止；再验证恢复、重复切换不会叠加循环，以及鼠标经过图表时仍能连续滚动会话。只有图表确实提供缩放等滚轮操作时才拦截对应手势。

## 趋势与 BI 的可信表达

- 明确指标、时间范围、单位、数据来源和截止日期。真实数据、预测和模拟数据分开标示；无法获得的未来月份或缺失值留空或说明，不自行补成一条完整走势。
- 同比、环比、累计值和当期值不能混作同一口径。金额单位转换后更新轴标签；比例标清 `%`，变动差额按实际含义标为百分点。
- 时间趋势用按日期排序的折线；类别比较用条形图；多指标量纲不同则分图或清晰标注。柱状图通常从零起，折线按数据范围留余量。不要用平滑曲线制造未观测到的峰谷。
- 用可见标记或简短标注突出关键变化。悬停/点击可查看时间、系列、数值和单位，触屏和键盘也能获取同一信息；仅在筛选或对比确实有用时添加控件。
- 多系列趋势图适合用图例切换显示时，将图例实现为真实按钮，绑定对应曲线、面积、标记和提示内容的显隐，用 `aria-pressed` 和视觉状态表达选择，并保留缩放、主题切换后的状态。宿主只负责呈现 HTML，不会自动把图例文字变成控件；上下涨跌等纯颜色说明不必做成开关。
- 验证点击时实际点按图例、图表或筛选控件，并确认可见结果；仅检查事件代码或在脚本中修改状态不算点击验证。遇到无响应，先区分宿主遮挡与 HTML 未绑定行为，不把“支持 JavaScript”等同于“所有图例都可点击”。
- 输出前实际预览：检查深浅主题、320px 和常规聊天宽度、全部轴标签、极值和缺失值、主要交互与主题切换。确认没有白色页面底、内容截断、无意义的内滚动或运行时错误。
