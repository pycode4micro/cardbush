# 工作簿与表格数据

先确定要读取、修改或生成的文件与区域。修改现有工作簿时保留与任务无关的工作表、公式和格式，默认另存为新文件。

## 选择工具

- `.xlsx` 的读写可使用项目环境已有的 `openpyxl`；大量数据分析可选 pandas，但不要因此把长编号自动转换成浮点数。
- CSV/TSV 可用 Python 标准库 `csv` 流式读取。保留原编码、分隔符、引号和换行约定。
- 先检查实际 Python 环境与所需依赖。CardBush 不保证 Python 或 Office 已安装；缺失时只准备完成当前任务所需的项目依赖。
- 宏、外部链接、数字签名、复杂图表和数据连接需要先检查保留能力。`keep_vba=True` 并不保证所有 Excel 特性都能无损往返；不为查看文件执行宏或更新外部连接。

## 工作过程

1. 读取表名、关键列和适量样本；大文件先看 [流式读取与精度](references/large-data.md)。不要将整本文件输出到对话。
2. 明确输入、计算区域和结果区域。需要随输入变化的结果写成公式；常量、日期和编号按实际语义保存。
3. 按 [工作簿编辑与校验](references/workbooks.md) 修改并保存；重新打开核对工作表、关键单元格、公式、格式及总计关系。
4. `openpyxl` 不计算公式。需要结果缓存时，可对普通 `.xlsx` 使用本技能的 `scripts/recalc.py` 和已有 LibreOffice，输出到另一个文件。缺少计算引擎时如实说明尚未重算，不能拿空缓存当作零。

按文件用途设置数值格式、列宽、冻结窗格和打印区域。可视化或正式交付要求排版检查时，用可用的表格软件/渲染器查看实际结果。

交付工作簿，并说明计算引擎是否运行、检查范围以及不能保真的特性。
