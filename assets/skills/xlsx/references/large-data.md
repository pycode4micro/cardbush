# 流式读取与精度

先记录文件大小、格式和需要分析的列。未知规模的数据从有上限的样本开始，输出中明确哪些部分未扫描。

- `.xlsx` 使用 `openpyxl.load_workbook(path, read_only=True, data_only=False)`，逐工作表用 `iter_rows` 限定行列。`max_row`/`max_column` 来自文件声明，可能被格式污染；不要按一个巨大声明尺寸分配完整二维数组。用完关闭工作簿。
- CSV/TSV 用 `csv.reader` 和 `itertools.islice` 读取有限样本，确认分隔符与编码后再流式扫描所需列。无法确认编码时不要靠忽略解码错误完成读取。
- 筛选、计数、汇总可按行或分块完成，不为简单任务先把全文件载入 DataFrame。需要准确总行数时应完整扫描，再把结果标明为完整统计。
- 账号、长整数编号和前导零按文本保留；金额等精度敏感计算使用十进制定点策略。Excel 数值型单元格中已经丢失的精度无法通过改变显示格式恢复。
- 处理不可信 OOXML 文件时使用更新的库及其推荐的 XML 防护；不解压到工作区外，不执行附件或宏。解析失败要报告具体文件与原因，不声称数据为空。

样本只说明该范围的情况，不能用前几十行证明整列的数据类型、无空值或无重复。
