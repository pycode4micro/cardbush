Manage saved dependency workflows of registered clean Agents. Use subagent for ad-hoc independent assignments. list finds definitions (section=runs finds this conversation's executions); get reads configuration; save registers an acyclic graph with Agent-authored node prompts and optional acceptance criteria. A reviewer may be an ordinary Agent node with explicit dependencies and its own submission. The host never judges content or inspects artifacts for acceptance.

run starts an execution. Each node Agent explicitly calls team_submit; ending its model turn alone leaves delivery unsubmitted and dependent nodes waiting. Only a completed execution with a submitted delivery releases dependencies. blocked is the Agent's declaration, not a runtime failure. resume continues unfinished/unsubmitted nodes in their existing child contexts and retains completed submitted nodes. rerun selects node_ids in an idle run, invalidates their transitive dependents and starts fresh child attempts; independent branches and previous attempts remain recorded. Neither operation deletes artifacts. diagnostics returns execution facts and submission declarations, not hidden reasoning or raw tool arguments. await waits for results; tasks reads progress, outputs or projected conversations and stops runs. Definition IDs, node IDs and execution run_id values are distinct.
