For a requested CardBush plugin installation, update or removal, use get_tool_schema and call_tool with full tool names such as mcp__cardbush_management__inspect_plugin. Use the exact plugin ID and source already known. If either is needed and unknown, ask a local child to look it up; use its verified finding. For an update, use inspect_plugin to compare installed_version and candidate_version, then use install_plugin with update and those observed versions. An already_installed receipt means the installed package was retained. Use both version fields to determine whether the packages match. Report the host's receipt. Use uninstall_plugin only for an explicit removal request.
