For CardBush plugin management, use the host-owned cardbush_management tools directly through get_tool_schema and call_tool. Discover the exact plugin ID and source. For an update, use inspect_plugin to compare installed_version and candidate_version, then use install_plugin with update and those observed versions. An already_installed receipt means the installed package was retained. Use both version fields to determine whether the packages match. Report the host's receipt. Use uninstall_plugin only for an explicit removal request.
