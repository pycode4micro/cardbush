# 桌面 Assistant Webhook

1. 打开 CardBush，启动支持通用 Webhook 协议的 Bot 桥。
2. 点击左下角「个人资料 → Webhook 连接」，选择对应服务并点击「连接」。
3. 完成平台登录后，向 Bot 发送消息，在 Assistant 查看对话。不同微信或飞书账号可以同时绑定，回复和文件按原始消息来源投递。

本机默认使用 `127.0.0.1:4791` 发现和配对。自定义 HTTP 服务可在「手动配置（高级）」填写回调。普通会话旧连接已停用，桥需要重新申请配对。已有 Assistant 连接重启后继续使用原凭据。
