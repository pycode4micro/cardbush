# 招财网站：仅远程子 Agent

管理中心 → **远程 Agent** 可注册、检测、编辑、停用和删除独立 CardBush Agent 服务。此入口不会创建进程、容器或本地 Agent，也不会自动装配角色、同步模型配置或插件。远程服务必须已由管理员独立部署。

## 1. 启动远程服务

在远程机器已构建的 CardBush 仓库根目录运行（Node.js 24+）：

```sh
node dist-electron/agentServiceCli.mjs --data-dir /srv/cardbush/agent-employee-a --name 商品切片助手 --host 127.0.0.1 --port 4780
```

Windows 可将数据目录换成 `D:\CardBushAgents\employee-a`。每名人员使用独立实例、独立数据目录；采用容器时必须分别使用独立卷，并只挂载该人员可访问的文件。不要使用桌面主配置目录，也不要把其他人员的目录挂进实例。

也可使用 `deploy/agent/compose.yaml` 部署原生独立服务。默认 Compose 只监听宿主回环地址，适合 SSH 隧道。HTTP(S) 直连则需要配置可达的 HTTPS 反向代理，或只对受信任内网开放 HTTP 端口。

通过 CardBush 原有 Agent 连接管理界面接入此服务，并为远程服务配置默认模型、必要的工具和指令。网站不会为远程服务自动安装插件或复制凭据。不要使用 `--disable-tools` 或 `--web-restricted`：前者不提供委派，后者是网站内部租户入口，不能作为外部服务注册。

首次运行后，访问令牌保存在该实例数据目录的 `access-token` 文件；也可由部署环境提供 `CARDBUSH_AGENT_TOKEN`。

## 2. 在网站注册

1. 管理员登录招财网站，打开 **管理中心 → 远程 Agent → 注册远程 Agent**。
2. 填名称与能力说明，选择 **SSH 隧道**：填写 SSH 服务器 IP/域名、SSH 端口（默认 22）、用户名、完整私钥和可选口令（也支持密码认证）、远端 Agent 端口（默认 4780），以及 Agent 的访问令牌。SSH 凭据和 Agent 令牌是两组不同凭据。
3. 在授权人员中勾选一人或多人，可按姓名、账号、公司、部门搜索，再点“全选当前结果”。搜索不清除已有选择；“取消当前结果”只移除当前筛选人员，“清空选择”撤销全部选择。勾选启用，保存后整批生效。
4. 首次点击 **检测连接**会显示 SSH 主机指纹。与远端管理员提供的指纹核对一致后，点 **指纹一致，确认信任**，再次检测。验证成功后点击 **验证并保存**。未知指纹不登录；已保存的指纹变化则拒绝连接。还会验证 Agent 令牌、CardBush 协议、委派能力及固定实例身份。
5. 让该人员在对话中说：“请让商品资料助手处理……”。招财通过 `list_subagent_options` 发现已授权目标，再用 `subagent` 异步委派、`await_subagents` 等待，或通过 `task_id` 继续原任务。

SSH 服务器必须能从 NAS 访问，SSH 服务需允许到 `127.0.0.1:4780`（或你设置的端口）的 TCP 转发。只创建 SSH 转发通道，不执行 shell/SFTP，不暴露本地监听端口，不启动远端进程。建议为每个人的 SSH 用户仅开放对应 Agent 端口。

远端 Linux 的主机指纹可由管理员用 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256` 查看；Windows OpenSSH 通常位于 `C:\ProgramData\ssh\ssh_host_ed25519_key.pub`。核对实际握手所选主机密钥的指纹。远端服务需要先完成模型和工具配置，隧道不代替服务部署。

仍支持 **HTTP(S) 直连**：填写例如 `http://192.168.1.20:4780/` 或 `https://agent.example.com/`，也兼容末尾 `/api/agent/v1`。公网直连必须 HTTPS，HTTP 仅支持内网。直连地址和 SSH 服务器地址均禁止 NAS 本机回环、链路本地地址及内嵌凭据。SSH 隧道的 Agent 目标固定为远端回环地址。

编辑已有连接时，留空保留原密码/私钥/令牌。更换私钥时同时填写新口令（无口令留空）；连接方式、服务器、SSH 用户、端口、指纹固定，改目标需新建连接。停用或删除不要求远端在线。

## 3. 自动切片技能

网站内置 `auto-video-slicing`，通过 `search_skills` 发现并读取；位置是 `assets/skills/auto-video-slicing/SKILL.md`。它只整理和委派任务，网站不会安装百应、剪辑或千川工具。远程 Agent 需要自行配置这些能力，并在注册时写清能力说明。

用户示例：

```text
帮我自动切片并上传：
登录手机号：<百应登录手机号>
主播名称：<主播>
原厂款号：<款号1>;<款号2>（或明确填写商品 ID）
千川账号 ID：<目标视频库账号 ID>
每款 1 条，开头用真实有吸引力的完整讲解，保留已有字幕，无字幕时加花字，翻页转场。
```

四项必填，缺项先补齐；手机号和账号/商品 ID 都按字符串保存。每组手机号、主播、千川账号分开委派。远端核对真实账号与商品，完成一条就上传一条，名称为 `yyyy-mm-dd_Ai_切片_原厂款号_主播名`，多条追加序号。未知上传结果先查原任务，避免重复；最终按款列出视频 ID、上传成功/失败和待补信息。仅要求计划或备料时按该终点停止。

## 权限与执行

- 只有管理员可修改注册信息；访问令牌、SSH 密码/私钥/口令在数据库中加密，保存后页面只返回“已配置”标记，普通账号和模型无法读取。
- 一个远程实例支持授权多名人员。旧的一人授权可直接编辑为多选，原有授权保持不变；不会自动授权所有人。同一实例的地址别名不能重复注册。
- 网站按账号和父会话隔离远程任务标识与读取权限。远端自身的工作目录、插件和登录状态仍是该服务管理的资源；需要物理资源隔离时分别部署独立实例和数据目录。
- 管理员已将网站远程委派默认权限设为“完全访问”（`all_free`）。网关向已注册、已授权的远程实例提交子任务时使用该模式；网站父会话仍使用网站自身的工具策略。已开始的旧任务不会被静默改写权限。
- 网站每次委派、读取、继续任务都会核对账号、授权和父会话归属。发送到远端的任务与会话标识经过账号隔离转换。
- 停用、删除或撤销授权后，新增操作立即拒绝，正在执行的远程任务在下一次授权检查时请求取消（每 10 秒检查）。远端不可达时不能保证即时取消；应在远端确认任务状态，避免重复执行。
- 原生异步任务和 SSE 进度读取机制保留。每个账号最多同时委派 4 个远程任务，网关最多 16 个；达到上限会明确提示先等待已有任务。
- SSH 断线后下一次读取重新建立受校验的通道，原生任务 ID 与事件游标继续使用；隧道层不重放制作、上传等操作。
- 委派只传任务文字，不自动发送主会话历史、个人文件、模型密钥或插件配置。远程文件仍保存在远端；本功能不自动把远程产物复制到网站个人文件夹。
- 模型不能注册、装配或启动本地 Agent，不能通过 `fork`、`clean`、插件角色、注册动作或旧的本地 `task_id` 绕过限制。
