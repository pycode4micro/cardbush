# 远程 Agent 文件交付与网页媒体预览（2026-11-14）

## 已部署行为

- 网页账号 Agent 可把明确选择的文件传给远程子 Agent。远端先建立属于该账号的委派工作区，再分块写入附件，最后提交任务；传输不调用生成模型。
- 子 Agent 最终回复中明确交付的本地文件会复制回发起账号的工作区，并将回复链接改为本机副本。不会扫描整个远程目录或把工具日志中的任意路径作为交付物。
- 单文件上限 2 GiB，每批累计上限 4 GiB，使用 512 KiB 分块、版本检查和最终 SHA-256 校验。传输失败会报告失败文件，不重新付费生成。
- 网页支持图片预览、音视频播放及文件下载。媒体请求经过账号认证，支持 HEAD、Range、拖动进度和流式响应，不将完整大文件转成 Base64。
- 附件参数用于新建远程任务；向已存在的远程任务追加附件暂不支持。
