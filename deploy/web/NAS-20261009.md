## 运维与回退

`cardbush-web` 提供网站；`cardbush-web-broker` 仅在私有网络内管理固定策略的用户容器。不要停止原 PostgreSQL 容器，新旧数据库都由它承载。原其他 NAS 服务不受本次替换影响。

本轮更新前分别保存 `backups/before-restricted-03`、`before-restricted-04`、`before-restricted-05`，包含数据库、配置与既有用户数据。升级保留命名卷，活动会话和图片任务完成后才替换旧用户容器。`20261009-02` 纯文字镜像及后续镜像均保留；需回到纯文字版时恢复 `before-restricted-03` 中的部署配置并重建空闲服务/容器，勿删除数据卷。

组织管理更新另存 `backups/before-organization-06` 和 `backups/before-organization-07`，包含数据库、配置、人员基准及既有用户数据；其中 `before-organization-06` 是增加公司层级前的基准。回退到不支持 `deleted_at` 的旧版时，应同时评估数据库兼容性，避免旧版把已删除人员再次当作可启用账号。不要自动覆盖发布后新产生的账号或会话。

网站健康检查：

```sh
curl --fail http://172.16.20.29:5199/healthz
```

需要回退时，由 NAS 管理员执行：

```sh
sudo /volume1/docker/cardbush-web/releases/web-20261009-01/rollback.sh
```

该脚本停止新版入口并恢复原网站 frontend/backend。旧镜像、容器、数据库和素材仍保留。新版上线后的账号变更不会自动写回旧库；回退前需核对新增账号及密码/审批变化。不要执行 `compose down -v` 或删除用户数据卷。
