# NAS 原生消息渲染更新

目标：`http://172.16.20.29:5199/`。发布根目录：`/volume1/docker/cardbush-web/releases/web-20261009-01`。

发布镜像 `cardbush-web:20261010-10` 基于已部署的 `20261010-09`。替换浏览器构建；后端仅更新 `webServer.mjs` 的会话工具记录只读接口，以及 `agentService.mjs` 中 `runtime.list_turn_tool_executions` 的受限模式读取白名单。队列、SSE、模型提供方、图片插件、文件隔离策略和 Runtime 包保持基线版本。管理员也不能读取他人会话的工具记录。

前端直接使用 Electron 消息组件、消息分组、执行过程、Markdown 和图片查看器。已发送消息的中间说明折叠到过程，最终答案只渲染一次；实时与历史均走相同原生投影。个人文件通过当前账号接口读取，原有缓存继续按账号隔离。普通外链通过浏览器打开，图片仅允许个人目录，不使用桌面桥接接口。

`updates/rendering-20261010-10` 保存发布文件、SHA256 清单、原生渲染源码依赖快照、合成浏览器截图和测试证据。`renderer-source` 中的依赖用于复现前端构建，不覆盖容器中正在运行的 Agent Runtime 包。发布前比对两个后端源码与 NAS 原版，确认仅上述接口差异。

验证包括原生 transcript 回归、26 项网页渲染/缓存/上传用例、真实 Runtime 的 13 项 Web API 用例，以及浏览器中的流式生成、切换会话、完成折叠、刷新恢复、复制最终回复、工具详情和图片缩放。浏览器夹具不调用模型、不使用生产账号；部署后另核对在线静态资源 SHA256、健康检查和未登录接口拒绝。

broker 的账号镜像同步为 `20261010-10`，使用原有空闲检查升级账号容器；执行中或排队的会话及图片任务不会被停止。用户命名卷保留。

回退文件位于 `backups/before-rendering-20261010-10`：恢复 `compose.yaml` 和 `config/broker.json`，重新创建 `web`、`broker` 服务。broker 将在确认账号空闲后恢复旧账号镜像。不要删除用户卷，也不要在有活动任务时强制重启账号容器。
