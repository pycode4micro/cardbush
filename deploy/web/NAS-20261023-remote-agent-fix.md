# 远程 Agent 查询修复与多人授权

部署镜像：`cardbush-web:20261023-26`。

## 原因

系统管理员最新会话 `web-d3a244a3fd2d6ab4489832059fc9848e9c5acf6e` 中，`list_subagent_options` 仅携带系统自动生成的 `_display_title`。受限工具策略在剥离展示字段前拒绝所有非空参数，误报 `web_tool_denied`；管理员实际上已授权一个远程 Agent。没有目标的 `subagent` 测试仍应拒绝，不据此判断远端不在线。

NAS 旧版启动入口未传 `bundledRoot`，服务默认使用 `/data/bundled`，而自动切片技能在 `/opt/cardbush/assets/skills`。此前的单元测试显式传了目录，未覆盖生产入口；现已覆盖未传目录的真实初始化路径，并断言工具返回的实际搜索结果。

## 修改

- 权限策略两次校验均排除展示字段，其他参数、授权、父会话和远程身份检查继续执行。仅允许注册的远程 Agent，不装配本地 Agent。
- 网站服务默认使用发行包内置技能目录，仅开放已审核技能和个人目录的读取。
- 注册及编辑支持多人授权，包含人员/公司/部门搜索、全选当前结果、取消当前结果、清空选择和已选计数，一次保存。保留原授权，不自动扩大权限。
- 旧的一人绑定记录可编辑为多人授权。远程实例仍禁止重复注册、替换身份及目标；按网站账号和父会话隔离委派/读取标识。远端工作目录与插件资源仍由远端自行管理。
